# 编程页 Confirm：保存目标与间接调用

从[20种Confirm原方法体](programming-confirm-bodies.md)归纳直接Save与下一层本地/子控件委托。对象/列表分类依据目标类继承声明与路径赋值；不能从Save调用推断现场落盘成功。[底层Save差异和IL](persistence-save-contract-review.md)。
[Save按钮](../../trunk/AKRS.ZX2200/Infrastructure/Controls/Feature/EditProgram/UcEditProductProgram/UcEditProductProgramming.cs#L1066)对当前页面可选地调用Confirm后显示成功消息；未实现接口时也可显示该消息。[Start按钮](../../trunk/AKRS.ZX2200/Infrastructure/Controls/Feature/EditProgram/UcEditProductProgram/UcEditProductProgramming.cs#L869)先调用可选Confirm，再进入[示教分派Start(true)](../../trunk/AKRS.ZX2200/Infrastructure/Controls/Feature/EditProgram/UcEditProductProgram/UcEditProductProgramming.cs#L1138)。这不是自动生产Machine.Start；详见[宿主入口与异常边界](config-submit-reload-review.md)。
