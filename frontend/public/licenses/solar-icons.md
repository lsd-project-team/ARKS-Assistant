# Navigation icon attribution

The three navigation icons are from **Solar Icon Set — Broken**, by **480 Design**:

- `Pen New Round` → 新对话
- `Structure` → 流程图谱
- `Document Text` → 功能说明

Source: https://github.com/480-Design/Solar-Icon-Set/tree/main/icons/SVG/Broken

Solar SVG artwork is distributed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

The source paths were preserved. Black paint was replaced with `currentColor`, and
the SVG files were combined into symbols to inherit the application's theme.
