# 模块化工程重构

开始日期：2026-10-16。

目标为用户确认的模块化单体结构。前端按业务功能归类；后端分离业务模块、Agent 编排和基础设施；交接工作台逐步抽出领域规则、应用用例、持久化实现和 HTTP 接口。

## 必须保持的行为

- 原有 API 地址、身份与权限隔离、源码引用和固定版本资料引用。
- 数据库表、迁移历史、附件、对话、运行事件和长期记忆。
- 根目录启动入口、业务源码只读、正式数据目录位置。
- 重构前已有的界面修改和未提交文件。
