# G0 坐标系专题

日期：2026-10-27。

## 页面与阅读方式

沿用“功能与流程”的主题、标题、阅读环节和节点说明样式，新增“G0 坐标系”专题。入口为 `/#topic/g0`；图谱目录中的 `g0-coordinate-system` 直接复用同一阅读页，不再重复展示专题摘要和空原图区域。

内容分为 7 个环节、29 个节点：

| 环节 | 内容 |
| --- | --- |
| 坐标关系 | G0、设备、相机、产品父链和零偏移辅助坐标 |
| 普通转换 | 正逆变换、逐层调用、弧度与长度单位、假设数值例子 |
| 相机转换 | 像素、拍照位置、VM 标定、模式和直接父级范围 |
| 加载与保存 | 加载绑定、创建替换、JSON 与标定文件、刷新、查找删除 |
| 标定与修正 | Init、多点标定、定位修正、人工覆盖与累加、工具缓存 |
| 生产应用 | S1 点胶、S2 固晶、晶圆台 XY 与单轴接口 |
| 使用边界 | 缺失或循环父链、未实现的逆变换、坐标结果与运动完成 |

图负责呈现关系和计算结构，节点正文解释条件和分支。普通变换公式、数值表和生产目标路径放在对应节点中。初版使用手绘 SVG；用户随后明确要求使用 Archify，已按下文替换为实际生成的交互图。

## 源码依据与实现

本专题依据 `trunk/AKRS.ZX2200` 的业务调用，沿引用阅读坐标库。65 条说明绑定 21 个文件的 40 个源码范围；其中 14 个文件首次进入现有证据清单。关键语义包括：普通坐标遍历父链、相机从属接口只执行直接父级变换、Bond 三维接口的一层转换，以及 Save、Refresh、对象替换和工具缓存的区别。

专题数据在 `frontend/src/features/knowledge/reviews/g0*.ts`，图表接入与公式在同模块的 `coordinates/`。现有 `SourceGuidePanel` 增加可选节点图表渲染入口，其他专题继续使用原结构。目录通过 `inlineTopic` 跳转到同一专题。生成索引同步更新；页面不增加源码快照或依据按钮。
