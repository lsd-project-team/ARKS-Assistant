# 问题与经验知识整理

2026-10-28，按用户要求处理现有问题与经验，让AI更容易检索、关联事实，并将不能可靠处理的内容交回人工。

## 数据处理

本机现有26条记录逐条补充检索关键词、明确条件、过程、措施和结果，并增加同主题记录的关联线索与使用边界。保留问题、经验、进展、归档的原有性质与处理状态；不将计算值、计划、初步判断改成实测或已完成结果。2条主要依靠图片的记录已补充可辨认的界面统计值，并明确转录来源。

每条仅新增1个版本，26条原版本、录入原文、21处原图引用及其顺序、来源日期和原录入人保留。首次写回在旧记录缺省空字段规范化时触发校验中断，核对后按规范化后的完整预期比对，接续余下记录，没有重复增加版本。其他交接记录未更改；SQLite完整性、外键和原图哈希检查通过。

12项人工确认内容包括参数单位、数值口径、机台身份、日期与图片对应、故障关联、交付关联、原附件及未解决事项的后续结果。资料、修改前快照、写回结果、人工清单和检索比较均位于本机 `data/knowledge-curation/20261028/`，不提交业务内容到GitHub。用户可按清单编号回复后再补充事实。

## 检索修正

检索原先把模块中的功能名称与用户明确的S1/S2区号直接比较，可能把没有填写区号的记录当成明确冲突。现对S1/S2筛选只比较记录中明确写出的区号；仅有功能名称时保留为“需确认”，不标为条件已匹配。明确的相反区号、设备、版本、加热条件和一般模块冲突继续排除。

- 40项后端检查通过，包含12项区号/冲突单元反例及新增的真实检索集成检查；Ruff通过。未采集覆盖率。
- 在本机整理副本上使用真实的本地混合检索，13个代表性问题中，所需来源全部进入前6项的覆盖由11/13变为13/13，本地语义检索正常。比较前后均使用本次修正后的筛选逻辑，因此这是内容整理的检索比较。
