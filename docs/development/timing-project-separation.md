# 耗时项目与聊天项目独立

日期：2026-10-27。

## 问题与结果

动作耗时的项目下拉框原先直接读取左侧聊天项目，数据权限与归档状态也绑定聊天项目。用户要求把耗时里的名称改为“智芯2200”时，误把聊天项目一起改名。本次恢复指定聊天项目原名“ZX2200 软件分析”，耗时项目单独命名、选择和管理。

耗时项目用于设备或业务的动作耗时台账，左侧项目用于组织对话。两者分别存储，聊天项目的创建、切换、重命名、归档或删除均不影响耗时项目及其分类、动作、耗时和备注。

## 实现与升级

- 增加 `action_timing_projects` 档案和独立新增、重命名接口；沿用账号访问控制、CSRF和版本冲突保护。
- 台账改用全局 `/api/action-timing/ledger` 接口，通过 `timing_project` 指定耗时项目，不经过聊天项目服务分派。旧项目下的台账地址退出使用；历史采集与暂停的源码模拟保持原边界。
- 页面独立读取耗时项目，下拉框旁提供“管理耗时项目”。不再读取聊天当前项目，也不修改聊天选择或列表缓存。
- 0024迁移仅为已有台账作用域增加耗时项目档案。沿用旧数据定位ID，未建立到聊天项目的外键；分类、动作、耗时、备注、原记录版本和时间不改写。旧页面的 `?project=` 地址可作为已有耗时作用域定位兼容读取，新地址使用 `?timing_project=`。
- 旧台账归属继续按原账号保留；无法确认归属的记录不猜分给普通用户。新账号默认创建空的“智芯2200”耗时项目，不生成动作或分类。
