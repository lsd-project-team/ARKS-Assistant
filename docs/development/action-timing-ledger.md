# 动作耗时台账开发与验收

日期：2026-10-26。当前需求以用户确认的简洁UI图为准：按分类维护动作，支持添加、编辑、导入和导出，耗时数据以后补充。源码模拟路线暂停，trunk只读。

## 实现

页面使用现有工作区导航，保留“交接工作台”下方的入口。左侧分类，右侧动作表格；顶部为所属项目、导入、导出和添加动作。列为动作名称、分类、耗时（秒）、备注及操作。空耗时显示“待填写”，0是有效值。下拉框复用shared/ui/Select，所有弹框复用shared/ui/Modal，按钮、输入和Portal浮层沿用现有主题变量。已在浏览器检查纯白、柔和灰绿和深色外观，并修正中等窗口宽度下工具栏换行。

后端在action_timing模块中增加独立台账服务、文件处理、导入事务和HTTP接口。0023迁移仅增加action_timing_categories与action_timing_actions两张表；不预置分类、动作或示例耗时，不转换历史模拟/采集结果。

- 分类新增、重命名、删除。删除时移动动作，目标分类有同名动作则整笔回滚，不删除动作数据。
- 动作增改删，支持调整分类。名称按Unicode兼容归一及大小写规范去重；同分类不允许同名，未分类也由数据库唯一索引约束。
- CSV和.xlsx导入、空白模板下载、行号错误提示、重复动作预览。Excel只读取第一张表，不执行公式，拒绝公式/错误单元格；表头和多余数据列不符时提示，避免静默丢列。单次5000行、5MiB，并限制Excel解压体积。
- 预览不写业务表，确认时验证台账版本并在短事务内整批写入。重复策略为跳过或更新；更新时空耗时保留原值，备注以文件为准。文件内重复行需先合并。编辑与删除使用记录版本防止并发覆盖。
- Excel/CSV导出全部或筛选结果，覆盖全部分页。导出文件与模板字段一致；文本公式安全处理与重新导入往返均有反例。
- 复用既有会话、CSRF和项目分派；个人独立工作区按账号隔离，归档项目只读，跨项目或账号的分类/动作不可读取或修改。

页面不再加载sourceTimingClient。旧source-analysis四个入口先检查会话与项目，再返回410；不构造分析器，不读取、重算或删除报告缓存。旧模拟实现和历史记录保留。此前未发布的完整循环实验改动已单独保存，不进入本次交付。

前端325项通过，类型检查及生产构建通过。浏览器实际完成分类新增、空耗时动作添加、编辑为0、CSV预览/确认导入、按分类筛选、下载空白Excel模板、导出筛选Excel并重新读取文件核对；刷新后数据保留，切换项目显示独立空台账，控制台无错误。普通用户与三种主题的弹框/下拉截图保存在本轮output目录。
