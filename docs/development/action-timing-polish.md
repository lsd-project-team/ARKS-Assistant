# 动作耗时页面、排序与单位换算

日期：2026-10-26。范围为整理现有台账页面比例、删除重复文案，补齐耗时排序和秒/毫秒导入换算。继续使用项目公共下拉框、弹框、按钮与主题，源码模拟保持暂停，trunk只读。

## 实现与使用

- 使用工作区容器宽度判断布局，避免窗口较宽但被导航挤压后仍保持双栏。宽工作区显示180px分类栏，窄工作区改为横向分类；表格列宽、工具栏间距及卡片边界统一。删除副标题、重复页脚、重复新增入口和空态说明。
- 点击耗时列头，依次切换降序、升序、默认顺序。后端先排序再分页；未填值始终最后，零值正常参与，同值采用稳定顺序。全部或筛选导出均沿用当前排序。
- 导入单位默认为按表头识别，支持中文秒/毫秒和s/ms。无单位的“耗时”列需选择秒或毫秒；显式选择与表头冲突时拒绝，避免千倍误差。切换单位后旧预览失效。
- 模板可按所选单位下载；自动模式下载秒模板。解析预览时将毫秒换算为秒，确认导入直接保存预览值，不重复换算。空值、0、小数均保留，非有限数、负数、布尔值和换算下溢不会伪装为有效零值。
- 无数据库迁移、预置动作或正式业务数据导入。
