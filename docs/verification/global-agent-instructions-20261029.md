## 数据与边界

本机 `8765` 服务已更新并通过健康检查。更新前创建本地备份，重启前确认没有运行中的问答；更新后 8 张正式业务表的数量和逐表内容哈希、全部检查点、资料文件及模型配置指纹与更新前一致。正式账号的全局指令没有写入测试内容。

真实模型只接收合成指令和数学问题；使用空源码目录、临时数据库，关闭 MCP 和记忆，供应商配置只在内存中复用，不复制到验收文件。测试不运行设备程序或 Docker。

未采集覆盖率和变异测试。模型验证仅证明本次连接下的默认指令与当前要求优先效果，不代表任意文字都会严格执行；全局文件仍服从系统权限和事实核查要求。后台记忆、摘要正文和事实核查模型不会自动改写该文件。

质量判断：账号归属、文件持久化、执行快照、上下文注入、共享访问、预算和恢复异常边界有实际反例；设置页完成普通账号持久化与草稿操作验收。测试中的供应商网络使用确定性替身，真实供应商另以合成场景验证。
