# 交接包确认与下载

2026-10-28～29，按用户要求将交接包列表、详情和历史入口统一显示为“未确认 / 已确认”。筛选保留“全部状态”，可按这两种确认状态查找；旧的待复核、拒绝记录统一归入未确认。归档仍由“查看归档”单独管理，原状态与固定修订不做批量改写。

管理员可从当前交接包详情直接确认，确认人取登录账号，提交时保留服务器版本冲突检查。普通用户继续只能查看和下载已确认内容，不扩大确认权限。交接包不再提供新的拒绝操作，旧拒绝包允许重新确认；其他记录类型沿用原审核规则。

未确认时下载按钮禁用；Word 和 ZIP 接口同时检查当前包和所选修订均已确认，不能通过旧的已确认链接绕过来源变化、归档或恢复后的重新确认。检查与快照读取使用原仓储锁，文件渲染在锁外进行，保留原附件和固定内容。
