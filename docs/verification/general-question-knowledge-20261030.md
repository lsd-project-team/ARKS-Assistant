# 普通问答被经验筛选覆盖的修复

## 原因和行为

用户反馈“你好”和“给我介绍一下vue框架”均收到“本轮返回的资料中，没有选到符合所问设备、时段或事项的内容……”的固定回复。

系统提示原本支持普通话题。实际缺陷位于经验核查：只要自动检索带入了候选，便进入历史片段筛选；筛选为空且没有源码引用时，程序无条件替换主模型原答。候选可能与本题无关，空筛选并不能证明普通问题无法回答。

筛选协议现明确区分 `general` 和 `records`，仍只向筛选模型提供当前问题和候选资料，不提供回答草稿：

- 普通问答不依赖本库历史事实，返回 `general` 和空选择；原答没有经验引用时保留，不再改成资料不足。
- 具体历史事实、试验结果和原图查询返回 `records`；没有相关记录时继续限制回答，不能以通用知识补造历史事实。
- 即便返回 `general`，回答中有实际经验引用时仍受原有核查约束，包含 Rich Content 正文中的引用；通用范围不能同时选择历史片段。
- 旧协议没有范围字段时，保守沿用记录查询处理；非法协议继续修复重试或报告处理失败。混合源码/经验与源码补引用的既有边界保留。

自动带入的候选提示也明确说明：无关资料应忽略，问候及通用知识照常回答。该修复没有新增关键词白名单或“只回答项目问题”的开关。
