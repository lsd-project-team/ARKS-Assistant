## Bugs Found / 修正与反例

1. **实施意图产品缺陷**：用户明确要求修改副本，但“原件不变；约束仅修改……”被否定正则跨分号拼接为禁止修改。真实模型连续调用创建工具被拒。收紧为同一分句内识别否定，保留其他分句的明确禁止、只讨论和询问限制。新增真实临时副本回归先复现失败，修复后通过。
2. **修改回答缺少原件引用**：第一次复测已经产生真实差异，但未读取原件、总结没有源码引用，严格引用检查失败。没有降低检查标准；补强项目代码工作提示，要求修改前核对原件、总结引用原件并用差异说明副本。再次复测引用、原件保留、修改和补丁回放均通过。
3. **评测入口不支持无上限**：底层策略已有明确 null 模式，但独立评测配置仍只接受整数。入口增加显式 null，保留默认值及有限范围；新增实际 Agent/SQLite 用量反例，模型替身累计超过旧上限仍继续、继续计费且不提升语义评审状态。未将真实供应商消耗用于该回归反例。
