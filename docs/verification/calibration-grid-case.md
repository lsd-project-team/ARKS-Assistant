## 可核对的输入与预期

构造 2 行、3 列的非正方形网格，起点 `(10,20)`，X/Y 间距分别为 2、3。每格使用互不混淆的点值 `(100+列号, 200+行号)`，均为合成数据。有效索引分别为列 0–2、行 0–1。

| 情形         | 输入示例                        | 本次需求的预期           |
| ------------ | ------------------------------- | ------------------------ |
| 起点、首格   | `(10,20)`、`(10.2,20.2)`        | `(100,200)`              |
| 末格         | `(15.5,25.5)`                   | `(102,201)`              |
| 内部网格线   | `(12,23)`                       | `(101,201)`              |
| 已经在范围外 | 左、下、超出右、超出上，共 4 例 | 返回输入坐标             |
| 精确右边界   | `(16,20.5)`                     | 返回 `(16,20.5)`，不越界 |
| 精确上边界   | `(10.5,26)`                     | 返回 `(10.5,26)`，不越界 |
| 右上角       | `(16,26)`                       | 返回 `(16,26)`，不越界   |

一共 11 例。内部格点的预期不同于输入坐标，可防止“全部直接返回输入”的错误实现混过测试；非正方形网格及不同 X/Y 间距可检查行列混淆。
