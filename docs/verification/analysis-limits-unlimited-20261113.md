# 分析与回复完整性设置精简

2026-11-13 按用户确认调整「设置 → 模型 → 分析与回复完整性」。

## 界面

- 保留「分析模式」下拉：自动识别问题范围 / 普通分析 / 深度分析。
- 删除以下数字输入框，不再让用户配置：
  - 普通工具预算
  - 深度工具预算
  - 关键源码复核预留
  - 深度分析回复 token 上限
  - 自动续写次数

## 运行限制

- 普通工具预算固定使用 128 次，深度工具预算固定使用 192 次。
- 关键源码复核预留保持 8 次。
- 自动续写上限提高到 8 次。
- 深度分析回复长度使用模型上下文允许的最大值，并给输入预留空间：
  `输入预留 = min(上下文 - 1024, max(8192, 上下文 × 5/8))`，
  `回复上限 = 上下文 - 输入预留`。例如 32768 上下文对应 12288 回复上限。
- 旧配置中的 24/64 预算和 2 次续写会在加载时迁移为 128/192 和 8 次；旧 `long_output_tokens` 字段保留兼容但不再参与计算。
