# AI 回答层次阅读验收

日期：2026-11-06。

## 变更范围

按用户确认的“层次阅读”方案，在 `AnswerMarkdown` 增加统一阅读容器，并在原有样式之后加载 `answer-reading.css`。纯白和深色分别设置正文、标题、辅助信息、行内代码、代码块、引用与表格色阶；灰绿外观沿用原语义颜色。正文默认 16px/1.85，窄聊天面板为 15.5px/1.8。

只调整前端渲染容器与样式，不修改原始回答、提示词、模型流程、解析协议或业务 API。正文、补充、来源顺序保留。标题与强调沿用原 Markdown 结构；工具状态颜色仅读取已有状态，不根据正文推断事实。
