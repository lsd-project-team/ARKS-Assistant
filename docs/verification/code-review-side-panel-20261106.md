## 本项目实现

- 点击聊天的“查看变更”或文件名，在现有右侧工作区显示代码变更，与聊天并排；不创建模态遮罩，聊天可继续输入。
- 文件点击携带完整路径，本轮快照继续携带运行编号；历史差异不会变成当前文件，也不开放历史撤销。
- 复用原 `CodeWorkDialog` 的查询、差异、验证、需求测试、历史及合并逻辑，增加嵌入式容器。管理员问答详情继续使用原弹窗。
- 面板通过 Portal 保留在当前聊天的 React 树中，使用同一个运行忙态；布局及关闭由应用层协调。文件树暂时收起，复用现有 `PaneDivider` 调整宽度。
- 关闭恢复原工作区、源码阅读行和触发按钮焦点；切换对话、项目或主动打开源码时退出旧面板，不覆盖新项目布局。草稿及用户调整后的宽度保留。
- 窄屏沿用现有“问答／工作区”切换；面板可直接关闭返回。Escape 在非输入控件中关闭面板，填写反馈时不会关闭。

实现文件为 `app/layouts/hooks/useCodeWorkPanel.ts`、`app/App.tsx`、聊天 `ChatPane.tsx` 与 `code_work/` 的摘要、容器和样式。没有修改后端 API、业务源码或验证命令。
