## 已测范围

- 同一整理主题下只命中一条时，不带入其他条目的正文、原文、来源路径和聊天编号；完整列表与版本不因检索改变。
- 无问题、空白、通用问句及无关主题返回空；“报警”等泛词不会单独扩大为其他设备经验。
- 选区路径匹配；原文依据和共用主题标题不扩大命中。
- 预算为零、极小预算、恰好容纳及少1 token；大条目跳过后仍可带入较小相关条目，最多6条。
- 来源聊天变化、账号及项目隔离；编码器只接收已按归属筛选后的文档。
- 本地模型缺失时关键词回退；实际本地多语言模型命中“停机后如何复工”对应的恢复生产条件，并排除界面外观记忆。
- 真实Agent装配、执行和运行来源事件，仅替换远程模型：相关问题带入、无关问题不带入、来源关闭不带入。
