# 停用新增项目共享结论

2026-10-29，按用户要求移除新增共享结论功能，保留已有记录和历史引用。

## 变更范围

- 移除聊天回复下方的保存按钮、弹窗状态和编辑器依赖。
- 移除项目资料中的新增共享结论入口，以及创建时的类型、来源消息参数和专用提示；管理员入口统一称为“项目资料”。
- 后端新增资料只接受文档字段，移除从回复创建结论、校验来源消息及关联来源的创建分支。旧版请求携带结论类型或来源消息时返回 422，不会静默保存成文档。
- 保留已有结论的数据库类型、来源关联、查看、编辑、回收站恢复、检索、导出和固定版本引用；不迁移或删除正式记录。

## 本机更新与界面验证

确认正式服务没有排队或运行中的对话后，将构建产物同步到 `frontend/dist/`，保留旧哈希资源并最后更新首页，重启服务后 `/api/health` 正常。刷新原浏览器时要求重新登录，因此登录后的界面验证使用 `localhost:8876` 的独立临时数据库和测试账号，不访问正式用户的私有资料。
