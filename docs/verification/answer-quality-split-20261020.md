# 筛选、事实核查与排版分离：同题复测

日期：2026-10-20。对照基线为[上一轮20题实测](answer-quality-20.md)：15道经验题、5道流程题，准确性3.30/5、阅读体验3.75/5、同时达标8/20。

## 实现边界

1. **资料筛选**独立调用，只接收当前问题和候选原文，不接收回答草稿。模型选择记录编号、字段与连续片段编号，程序从固定版本快照取回原文。事实审核与终审不再重新筛选、复制原文或改版本。编号合法不代表语义相关性已获得证明，相关性仍由模型判断。
2. **回答生成**保留正常模型自主归纳。对流程问题中超过1500字符的源码草稿，增加一次围绕问题的流程整理；只有已要求源码事实核查的运行才启用。整理稿只能沿用原有引用，不能直接发布，之后照常通过源码引用检查和事实核查。详细、逐字、逐行要求及代码修改任务不受该收束逻辑影响。
3. **事实核查**只处理条件、日期、数值、单位、结果、判断归属、适用边界与是否回答了问题。保留选中片段及该批选中记录的完整正文上下文，避免把片段遗漏写成原记录没有；不能据此加入其他时段或设备的事实。格式问题不再触发事实修订或拒答。真实修订稿需要终审核查；仍有错误不能因为它是第二稿就放行。协议问题只修复一次，输入超限、空输出、无效结构、供应商异常、事实仍未解决分别记录。
4. **最终排版**不调用模型，仅调整长段分段、大块加粗，以及明确的纯参数组合行。代码、引用、表格、原文提取、公式和叙述句保留。参数行遇到跨项加粗或叙述内容时不拆，避免破坏Markdown或句意。排版失败保留原回答，不把处理失败说成资料不足。

经验和明确要求源码证据的流程回答，均在核查完成后显示最终稿；内部筛选、流程整理和复核输出不作为用户token流发布。最终显示和实际保存内容需要一致。

主要代码：[筛选](../../backend/app/agents/runtime/knowledge_scope.py)、[事实核查](../../backend/app/agents/runtime/knowledge_answer.py)、[复核协议](../../backend/app/agents/runtime/review_protocol.py)、[流程草稿整理](../../backend/app/agents/runtime/answer_draft.py)、[最终排版](../../backend/app/agents/runtime/answer_presentation.py)。`trunk/`、正式业务记录与模型配置未修改。

## 未解决的具体问题

- **E03**：否定“每个点均提高2μm”的主结论正确，却把精度改善解释成坐标整体加2并推出新范围，还从无配对样本断言某点没改善。这类自主解释仍需核对逻辑，不能只检查是否重复了原始数字。
- **E10、E11**：仍扩写确定机理、组合必要性或未经资料支持的试调起点。E10把216颗当作可参考的通过标准，原记录没有授权这个验收标准。事实核查模型未完全拦住这些问题。
- **E13**：正确说原文没写高度单位，随后又按设备习惯猜内部坐标/计数档位；标作推测也不能满足本题不补猜含义的要求。
- **F01**：主流程写到，但将 `SelectedText` 比较简化为选索引5/6必启用参数组，停止生效时机也过于确定；展开过多实现细节。源码上下文未完整提供给复核器，最终为unknown。
- **F02**：准备失败弹窗概括与自身表格的静默分支矛盾；又断言未读取底层的失败后轴位置。复核正确识别两处问题，却只在尾部追加纠错，错误正文仍在。耗时425.84秒。
- **F04**：Cancel/try/catch/finally主分支正确，但异常汇总表把调用失败简化成生产未启动；同一结论以正文、表格、尾句多次重复。
- **F05**：错误声称未配置安全门时左侧传感器读取不会发生。实际 `!IsSafeDoorClose && IsSafeDoorConfigured` 先求左值，再决定是否求右值；配置为false不消除左侧读取。另把 `AbsoluteMove(0)`称为回零、外推全部门检查。本题标记严重事实错误；末尾unknown提示不能抵消错误正文。耗时506.99秒。

流程整理环节本轮没有接受到合格短稿：实际返回的候选未满足长度/原有引用约束，均记invalid_draft并保留原稿继续核查。这个保守约束避免直接放行无法核对的短稿，但没有带来预期的流程收束，还增加模型调用。F03本轮主稿本来就较短且事实正确；不能把它的表现归功于并未发生的长稿压缩。

源码复核仍使用现有[SourceEvidenceGuard](../../backend/app/modules/source_analysis/evidence.py)及[review_answer](../../backend/app/modules/source_analysis/review.py)：unknown只加提示；二次needs_correction也可能只追加原因。这是F01、F02、F05残留问题的具体代码路径。本次已拆开经验筛选、经验事实核查和最终排版；**不宣称已解决源码复核的所有失败出口，也不宣称所有模型结论已经核实**。
