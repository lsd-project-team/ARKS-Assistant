# 问题与经验在回答前筛选

用户要求：检索后先让AI筛选相关内容，只有选定内容进入回答上下文，保留回答后的事实核查。相关性筛选判断资料与问题的关系；事实核查检查尚未生成于筛选阶段的回答是否忠实于原文，两者分别执行。

## 实现边界

`KnowledgeRetrieval` 在搜索、按编号读取及前文引用核对的入口统一筛选。候选只交给独立的 `KnowledgeSelection` 请求，不向其提供回答草稿；复用既有编号协议和校验，程序从本轮固定版本取回选中原文。回答模型的工具结果仅包含已选原文与对应元数据，没有未选记录的正文、标题或引用。检索候选计数仍可用于记录搜索过程，实际来源只登记选中的记录。

同一轮的同版本复用筛选结果，并行读取不会重复请求；多条候选按输入预算分批，一批失败时整次新筛选不公开部分结果。没有候选时不请求筛选模型。超时、输入超限、供应商失败和无效协议均不回退原始候选；取消继续向上传播。历史引用必须核对当前固定版本，版本不符不能借用其他版本。

运行图将工具已选范围传给最终核查，不重复筛选；核查模型可看到选中记录的完整正文用于核对遗漏，回答模型只看到选中片段。事实修订后仍执行终审，失败只摘录已选原文。空筛选的历史查询不能放行补造的结果，通用问答可正常回答；处理失败与没有适用内容分别报告。实际调用经验工具后，草稿及续写中间稿等最终处理完成再显示，避免空筛选时提前流出未核实数字。

三句项目相关性路由提示不变，普通问候和Vue介绍不增加筛选调用。没有修改前端、正式记录、长期记忆生成、账号权限或数据库结构。
