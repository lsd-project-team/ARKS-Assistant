# 经验条件提醒与内部提示去重

2026-11-01，用户要求去掉泛泛的经验核对提醒，只保留影响处理办法的具体条件，不在回答末尾重复提醒，并精简内部重复提示。

## 修改范围

- `debug_matching.py` 保留 matched、needs_confirmation、mismatch 与匹配/缺项字段；前两种状态不再附带“核对设备、版本、模块、工况”或“仍需现场验证”的泛化原因。明确冲突仍返回具体原因，不放宽筛选。
- `system.py` 要求具体条件紧邻对应办法或参数且只说一次；未填写某项信息不自动变成追问或结尾提醒，用户未问其他工况时不假设差异后追加警告。移除未接入运行的旧 `DEBUG_ISSUE_GUIDANCE`。
- `debug_issues.py` 的经验规则由 1,433 字符缩为 511 字符，删去与主提示重复的表达、排版、事实和来源位置要求，保留匹配字段、历史状态、原图及引用协议。
- `graph_builder.py` 每轮只在系统提示装配一次经验规则；`knowledge_selection.py` 的搜索和分页工具结果不再反复提供 `display_hint`。
- `knowledge_answer.py` 独立事实复核保留具体单位、条件、范围、图形和引用核查；明确允许在事实无误时清理泛化尾注，避免与“只修事实”的旧要求冲突。具体参数单位的确认方法、用户所问适用范围及逐字原文不属于清理对象。清理该提示内部重复的组织和图形保留要求，不新增模型调用或提高复核次数上限。

没有新增删提醒的模型调用或字符串过滤器，不改写历史消息、正式知识及引用版本。只影响新生成和重新生成的回答。

## 验证方法

复用现有测试和临时数据库，扩充已有断言检查：缺项状态不生成泛化原因、明确冲突原因保留、回答模型每次只收到一份经验规则、搜索和读取工具不重复携带展示提示。检索片段筛选、事实错误修订、未知单位、原图、富内容和引用链路仍走真实实现，外部供应商在自动化回归中使用既有确定性替身。

真实模型实测复用 `scripts/verification/answer_style.py` 的隔离场景，覆盖降低参数仍刺穿的处理、具体芯片规格与未知高度单位、075 顶针能否推广到其他尺寸。仅使用合成蓝膜资料和临时数据库；当前供应商配置只用于调用，不写入日志。首轮发现已交代的尺寸仍被改写到结尾，随后收紧主提示和复核规则并重新执行。

测试、实测及发布记录保存在 `output/experience-conditions-20261101/`。提示词约束不能保证所有未来生成均符合表达偏好；本轮没有重写既有回复，也没有做真实设备验证。覆盖率未采集。

## 最终结果

- 17 个测试文件、183 项回归：183 通过，0 失败，0 跳过；最终记录为 `tests-final.log`、`tests.xml`。修改的 8 个 Python 文件通过 Ruff 检查及格式检查。
- 当前供应商真实复核定向场景 3 项通过（`review-results.json`）：删除截图同类尾注；保留高度单位未知及查看本机参数界面的方法；保留用户明确询问的其他尺寸适用范围。解决办法、数值与真实引用均保留。
- 当前供应商完整 Agent 的最终 3 个隔离问答均完成，未再出现原设备/版本/模块/工况的泛化尾注（`live-results.json`）。这组抽样不代表所有推断和表达均已达到理想质量；仍观察到个别解释重复和单位量级推测，本轮不据此宣称全面语言质量验收通过。
- 中间实验发现清理范围过宽会误判具体参数确认方法，且出现事实复核未收敛的原文降级。保留这些中间结果（`live-results-legacy-final.json`、`live-results-broad-review.json`），最终将清理范围限定为泛化尾注，不删除必要条件或放宽事实、来源核查以获得通过。
- 回归涵盖字段缺项和冲突、阶段筛选、并发缓存、失败及超时、片段隔离、事实修订、普通问答、原图和富内容、固定版本引用。没有修改前端，本轮未重复前端构建或浏览器视觉验收。
- 质量判断：匹配与提示装配有实际集成回归保障；模型表达为中等置信度的抽样验证，非确定性保证。未做设备或全项目回归，覆盖率未采集。
