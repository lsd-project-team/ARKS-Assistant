# 独立对话与项目对话的默认源码能力验收

验收日期：2026年10月19日。

## 要求与实现

独立对话能查看默认 ZX2200 源码对应的流程图谱和功能说明，同目录源码引用在右侧打开、定位并同步选中代码树；项目专属配置、账号权限和已暂停的 AI 回答来源维持原规则。

问题原因为前端以当前项目资料判断源码身份与图谱可用性，而独立对话没有项目资料，导致同一默认目录被误判为外部来源，并显示资料空页。现在两种对话通过受权限保护的源码上下文接口读取真实目录身份，不将缺少项目资料等同于缺少默认源码。

Test Files：前端全量，新增 `frontend/tests/source_reader/source-citation.test.mjs`；后端项目集成、公司共享源码及账号所有权、源码工作区、来源开关、暂停来源和架构测试。

Test Cases：前端 272 项，后端所选 70 项。前端 272 Passed、0 Failed、0 Skipped。后端首轮 68 Passed、1 Failed、1 Skipped；失败为新增用例用管理员创建项目时漏填默认目录，属于 Test Data Problem。补齐明确目录后，新接口文件的 3 项全部通过；原先通过的 68 项未受此测试数据变更影响。最终所选用例均已有通过证据，1 项符号链接检查因本机 Windows 未启用创建权限跳过。Coverage：未采集。

用例执行真实引用 Hook、查询客户端和工作区状态，只隔离 HTTP、提示及 React 外部状态订阅。覆盖独立/项目相同源码身份、首次等待元数据、两个异步阶段的项目切换、附加目录前缀、真实外部历史来源、版本与行数失效、网络失败和读取证据约束下的多行范围恢复。后端验证登录、跨账号 404、项目删除、目录改绑、附加目录以及独立上下文不携带私人指令和说明。暂停来源集成测试继续通过。
