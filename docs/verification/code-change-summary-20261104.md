## 数据与交互

- 新增只读 `GET /api/p/{project}/threads/{thread}/code-work/summary`，沿用项目、对话与账号权限；未创建副本时返回空摘要，不创建目录。接口不返回源码正文或验证日志，不扫描构建依赖清单。
- `code_work/changes.py` 共用摘要与详情的基线差异计算。按原始基线与当前已保存文本生成统一差异，跳过两行文件头统计增删；真实内容以 `+++` 开头仍计入。重复编辑按最终差异计数，不叠加操作次数。
- 摘要校验文件版本，发现外部未记录修改时显示错误及重试，避免继续展示错误统计。仅编码、换行或文件末尾换行发生字节变化时，文本增删数可能为0，文件仍列出。
- 卡片表示当前对话副本的累计差异，显示“当前副本”；不记录某轮历史回复的独立快照，也不表示验证通过。刷新直接读取既有修改，无修改时隐藏。
- 聊天运行时每1.5秒刷新摘要，运行结束重新读取；面板撤销后共同失效缓存并更新。项目、对话和运行状态分别纳入缓存键，防止串用其他副本。
- 路径缩略优先保留文件名，悬停和无障碍名称保留完整路径。浅色、深色及窄屏复用现有主题。未新增整批撤销；详情继续使用原逐文件撤销确认。
