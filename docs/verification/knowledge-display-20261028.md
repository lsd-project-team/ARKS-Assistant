## 实现范围

- 问题列表不再用归档标记替代处理状态；详情和引用详情不显示修订号。编辑、归档、恢复、查看引用内容和打开最新记录继续使用后台原有标识与修订校验。
- 交接卡片、打包选择、包内问题记录和聊天上下文中的问题引用同步隐藏管理信息。资料、源码和其他业务记录仍沿用各自的版本显示规则。
- 新 AI 回复的经验引用由服务端统一输出为资料标题，定位地址继续保留原记录与固定修订。历史回复仅在渲染引用时隐藏原来附加的修订后缀，不改写已保存消息，也不改写代码示例。图片仍按回答实际引用的固定内容加载。
- 回答提示明确禁止输出这五类记录管理信息；设备软件版本、工艺参数、原始日期和结果属于业务内容，继续保留。此规则不能代替真实模型答复质量验收。
- Excel 目录保留九列；逐条内容、离线网页、业务 JSON 和图片清单也删除相应管理字段。工作簿原图和 ZIP 原始图片继续保留，核对用的映射和指纹只存于本机工作目录。
