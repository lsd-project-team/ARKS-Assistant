# 经验回答的归纳与事实边界验收

日期：2026-10-19。供应商模型：DeepSeek-V4-Flash。

## 问题与实现

真实模型基线复现：用户只输入“蓝膜刺穿处理经验”时，模型沿用旧回复的“问题、方案、结果、经验”分栏，并将原记录中的“主因、根治”直接作为结论。此前的提示词接入和86项自动回归没有验证这种真实生成行为。

本次调整主题问法的默认意图，要求提炼认识并用必要事实解释，避免重复列字段。原记录人的因果解释须保留归属；组合成功不证明单项独立有效，也不证明各项缺一不可。未提供对照数据不等于没有做过对照；本轮检索结果不等于全库清单。

新增 `KnowledgeAnswerGuard`，在经验回答生成后按本轮实际返回记录的固定版本复核。自动带入与工具读取共用来源事件，未检索的记录不送入复核；保留工况匹配信息和来源引用，排除附件内部信息。合格回答保留；需要修订时给出完整新稿，并再次终审核对。每个候选最终回答最多两次复核调用，仍未通过、预算不足或供应商失败时降级为明确标注的原记录摘录，不能把新分析当作已核实结论。摘录保留常见凭据脱敏。

复核JSON不进入回答流；修订在模型中间件中完成，页面最终替换、检查点和正式回复使用修订结果。模型调用用量独立记录为 `knowledge_verification`，沿用项目模型额度回调。关闭知识资料或没有实际经验来源时不调用这项复核。

另修正“完整原文，不要改写或分析”误触发深度源码审计的问题，同时保留完整流程、调用链等原有深度问法。

## 真实模型验证

所有实测均使用临时数据库、临时空源码目录和用户提供的蓝膜案例，旧分栏回复由同一案例合成。只读取当前供应商配置，不读取或发送正式历史对话、其他经验、业务源码；密钥只在内存中绑定，不复制进临时配置。真实调用会消耗供应商额度。

逐轮检查五类问法：新对话主题、带旧分栏历史的同题追问、分析与建议、完整原文、075是否能独立根治及其他尺寸能否推广。人工检查最终文本，不把模型复核器自评通过当作效果验收。

- 同题追问已从原分栏变为自然归纳，保留025/050、075、20~30g、3mm/s、280~300、216颗等关键事实；原记录人的原因解释有明确归属。
- 新对话主题能将处理过程与结果串成自然段，不重复输出问题、方案等字段清单。
- 分析回答能区分已观察结果、原记录人归因和待验证解释，不以“合理机理”为由认定已证实因果；建议与实际执行结果分开。
- 完整原文按原内容返回并保留引用，未再出现无关源码搜索或缺少源码提示。
- 推广问法会限制到本次组合与条件，复核曾纠正“库里只有一条”的全库断言；调优中未通过的稿件被明确降级，而非当作正常分析发布。

最终反向因果边界定向实测已通过人工检查：回答区分“本记录不支持075独立有效”和“075独立无效”，将主因与根治归属为原记录人判断，保留216颗和对应规格的范围，没有声称各参数缺一不可或已验证其他规格。模型复核自评仅作辅助。

同题追问实测回答节选：

> 原记录把问题归因于小顶针应力集中，换大一号顶针分散受力，再配合低速低力才解决，并指出只调单项参数效果有限。需要说明的是，记录没有提供单因素对照数据，所以不能认定四项中哪一项独立起效；这个组合在记录条件下的有效性不能直接推广到其他芯片规格或顶针配置。

本机产物：`output/answer-style-baseline.json`（真实反例）、`output/answer-style-final.json`（五类逐轮结果，含一次未通过后的降级）、`output/answer-style-release.json`（关键两类复测，含应用源码哈希）、`output/answer-style-generalize-accepted.json`（反向因果边界定向复测）。这些文件不作为正式业务记录保存。

可显式复现：

```powershell
$env:PYTHONUTF8 = '1'
& backend/.venv/Scripts/python.exe scripts/verification/answer_style.py --live --cases history topic advice verbatim generalize --output output/answer-style-live.json
```

## 限制与质量判断

经验复核增加一至两次模型调用，会增加等待时间和供应商用量。它仍是模型判断，可能漏判；程序模板和范围检查也只覆盖明确形式，不保证所有表达。新增实质复核针对“问题与经验”来源；源码沿用原有源码复核，其他资料的自然表达由系统提示指导，不宣称全部资料类型均已获得同等语义复核。

未执行设备动作、未验证真实工艺效果，未覆盖其他供应商和全部业务问题。测试质量：中，理由是具备真实反例、当前模型样本、持久化与失败边界回归，语义效果仍是有限样本验证。
