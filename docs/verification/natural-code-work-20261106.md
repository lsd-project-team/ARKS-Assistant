# 自然语言代码修改入口验收

日期：2026-11-06。

## 变化和边界

- 新对话无需 `/修改代码`、附件或已有副本即可获得副本工具，由本轮模型理解软件问题及功能需求；不增加关键词路由或单独的意图分类调用。
- 只有模型实际调用准备工具才复制工程；普通解释、方案讨论、明确暂不修改的请求只回答，设备操作和工艺经验问答不自动转为改码。
- 输入框删除改码命令；差异反馈、补充需求断言及面板返回草稿均使用正常正文，原草稿保留。旧前缀消息仍按普通需求理解。
- 工具继续绑定当前对话，原工程只读，实际修改仍需版本核对、需求断言和固定验证；合入沿用管理员确认。
