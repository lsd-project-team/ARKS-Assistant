# 原地编码 Agent 完善验收

日期：2026-11-13。对应设计：[原地编码 Agent](../features/in-place-coding-agent.md)。

## 本轮完成

- **审批闭环**：命令/后台任务审批在工具线程内等待，SSE 推送 `coding_approval`；批准后同轮继续，拒绝、超时（300 秒）、取消都有明确结果；`start_process` 审批按后台执行。
- **实时输出与取消**：执行器边读输出边写日志并推送 `coding_output`；运行取消同时结束等待中的审批和前台命令；后台任务自然退出后自动回收。
- **精确编辑**：新增 `edit_file`、`multi_edit`、`write_binary_file`；保留原编码、BOM 和换行，替换冲突需要更长的原文或 `replace_all`。
- **查找**：新增 `find_files`；`search_files` 优先 ripgrep，支持同一文件多个命中，回退剪枝遍历；排除构建与缓存目录。
- **设置面板**：审批档位、超时、构建/测试命令、只读项目启用；按工程文件识别语言和默认命令并注入提示。
- **检查点**：只读项目不再创建快照；选中检查点显示自身差异；单文件恢复；撤销本轮；可读标签；命令执行前自动存档。
- **安全与降级**：只读项目的写入、删除、命令和回滚统一被拒绝，提示词明确告知模型；项目外破坏性命令直接拒绝；git 不可用时文件读写仍可用。
- **审计与最近审批**：管理员可在编码面板查看命令记录；最近审批展示结果和输出末尾。
- **轻量运行修改接口**：`GET /api/runs/{id}/coding` 只读本轮修改事件，回答末尾卡片不再拉取完整运行上下文。

## 尚未完成

- 未在真实 DeepSeek 账号上重跑完整"从空目录到可运行程序"任务，本轮以框架、API 和真实命令执行为准。
- 审批等待期间如果服务重启，等待中的审批会丢失；运行恢复逻辑会将会话标记为中断。
- 编码仍不是操作系统级安全沙箱；"全部放行"档位只拦截已识别的危险命令，不能替代容器或受限账号。
- 大仓库首次建立快照仍可能较慢，本轮只做排除目录和只读保护，没有做后台建库进度。
