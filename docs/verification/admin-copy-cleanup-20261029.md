# 管理端辅助文案精简

日期：2026-10-29。

## 调整范围

- 清理管理概览、用户管理、问答记录、系统配置和数据维护中的英文装饰标签、重复副标题与功能介绍；删除侧栏重复的分组提示。
- 概览指标保留名称、数值和单位，统计口径及采集时间统一放在已有折叠区。
- 系统配置清理重复的当前模型提示、检测介绍、MCP 介绍、外观说明、长期记忆介绍及底部常驻说明。
- 成功的模型检测默认折叠，展开后仍可查看四项结果；失败结果默认展开。压缩模型的留空含义继续通过输入框占位文字说明。
- 知识来源使用紧凑布局，选项说明可悬停查看；普通聊天中的知识来源选项保留原布局。
- 精简项目设置和项目验证命令入口的重复说明，以及管理端交接页面的标题说明。
- 必要的字段标签、单位、状态、记录时间、错误反馈、未保存提醒、备份限制和恢复步骤保留。没有通过通用 CSS 隐藏全部小字。

相关无用样式随对应元素移除。配置、数据和权限接口没有改变。

## 检查中发现并修复的问题

未配置 MCP 服务时，`tested?.signature` 与 `JSON.stringify(undefined)` 都是 `undefined`，比较结果为真，随后访问 `tested.result` 导致整个页面白屏。

现在先确认检测记录存在，再比较配置指纹。新增真实组件渲染回归，覆盖空服务列表，以及仅显示与当前配置匹配的检测结果。新增用例在修复前复现 `TypeError`，修复后通过。
