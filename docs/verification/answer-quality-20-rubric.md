## 数据与范围

- 经验题依据用户提供的蓝膜记录及两段adv-3记录，另造不同日期、近似设备名两条干扰记录。干扰数据不是实际设备事实；不向被测模型标示“干扰”或直接提示应排除的理由。
- 流程题使用当前 `trunk/AKRS.ZX2200` 只读源码，带入明确选区并允许沿调用继续读取。分为全局标定、吸嘴校准、顶针校准、生产启动、启动前准备。所测为代码所示流程，不等于已验证设备操作SOP。
- 数据库、账号、对话、检查点及图片均为隔离夹具。测试图片用于检查固定版本、重复位置和回答引用对应关系，不评价真实设备照片内容，也不把模型没有识别的图片描述当成事实。
- 每题保存实际回答、用量、时间、选定片段、复核与引用证据。超时和错误保留；调试与正式批次分开，应用或数据指纹变化后不得续写旧成绩。

## 准确性：0—5

| 分数 | 标准                                                                            |
| ---- | ------------------------------------------------------------------------------- |
| 5    | 所问关键事实完整，设备/阶段/数值/单位/顺序/归属正确，引用可核对，无越界确定断言 |
| 4    | 主结论正确，无实质错误；有轻微遗漏、范围措辞或引用表达问题                      |
| 3    | 有帮助但不完整，遗漏关键条件或出现未经资料支持的建议/解释；需要修改             |
| 2    | 实质错误、阶段混淆、把因果推断当事实，或退回摘录未完成所要求的分析              |
| 1    | 回答主要错误或多数内容与问题无关                                                |
| 0    | 无有效回答、超时/调用失败                                                       |

严重范围错误、编造设备结果、错误版本/其他设备原图等单独标记，不以平均分抵消。无法确定的条件应如实说明；“本轮资料没有符合内容”不能写成“整个库没有记录”。原文题按忠实提取判断，不因原文中的历史判断扣分。
