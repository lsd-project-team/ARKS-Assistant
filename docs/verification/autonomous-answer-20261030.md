# AI 自主格式与基础问答链路验证

日期：2026-10-30。功能约定见[自主回答格式](../features/answer-format.md)。

## 变更范围

移除 `FlowAnswerDraft`、流程布局约束、最终自动排版及前端正文整理插件。主模型可自行选择 Markdown 或已有结构化组件；格式中间件只校验并记录结果。保留源码搜索、实际读取、引用范围与版本检查、语义复核、事实纠正、输出恢复和历史保存。

源码相关回答在证据核对完成后发布最终稿；普通回答继续流式显示。格式损坏由现有前端降级展示原文，不发起排版模型调用。

## 已测行为

- 实际 Agent 图执行源码搜索、读取和语义核查，保留 AI 选择的长加粗段落、Markdown 表格及结构化正文；不调用流程整理器或最终排版器。
- 最终正文、流式替换、数据库历史与事件重放一致；临时源码字节保持不变。
- 现有引用范围、来源版本、失效证据、错误结论修正及混合经验回答回归通过。
- 结构化内容的未知版本、非法类型、损坏 JSON、未闭合围栏被报告，校验不改写内容；普通代码中的协议示例不误判为内容块。
- 实际 React 渲染保留强调、来源段落、版本标签和展示文字，表格、代码、结构化组件及原文降级回归通过。
- 本轮构建的登录依赖可匿名读取；私有脚本和知识资源仍要求有效会话。

真实模型场景分别完成一个自然段的通用回答，以及源码搜索、读取、有效引用、语义复核和纯 Markdown 表格回答。只发送合成问题与临时源码，正式模型配置只读入内存，没有复制密钥或写入正式聊天。

## 失败归因与修正

首轮完整回归中，6 项旧断言仍要求自动去掉长加粗或压缩流程，已按本次需求改为验证原格式保留。另 1 项检索测试用裸数字判断内容泄漏，随机 UUID 恰含相同数字时误报；现检查对应事实原句，保留筛选及事实纠正断言。

构建发现 Git 恢复后的换行转换使既有图谱指纹不匹配，已明确 HTML 与规格 JSON 的检出换行规则，并核对现有 SHA；资源正文和既有指纹未改变。

## 数据、发布与限制

没有新增数据库迁移，也没有清理、重建或导入正式数据。发布前确认无等待或执行中的聊天；保留旧哈希资源，最后切换入口和公开资源清单，再重启同一个数据目录的服务。

发布后健康检查通过，HTTP 返回的首页与本轮构建逐字节一致，公开入口脚本指纹匹配。只读核对正式账号、项目、对话、消息、交接记录及修订、附件、长期记忆及生成成果数量，发布前后一致。`trunk/` 未修改。

浏览器自动化连接不可用，本轮没有完成实际页面目视和点击验收；展示依据为实际 React 渲染测试、生产构建及 HTTP 资源认证。未运行设备，也未重新评价所有真实业务问题的回答质量。

本次测试质量判断为中：核心链路、异常及数据一致性已有自动化和两个真实模型场景验证，浏览器目视与更多业务场景仍未覆盖。
