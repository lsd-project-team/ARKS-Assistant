# AI 回答与记录文字的呈现

验收日期：2026年10月19日。

## 行为与版式

AI 先结合记录事实直接回答问题，再用自然段说明结果与变化，少量加粗关键数据；原记录人的判断保留归属，AI 推断必须明确标注。回答不再逐项复述记录标题、记录人、条件和原图清单，记录文字由下方页面完整展示。

记录区采用轻分隔线、文件图标、记录标题、原记录人及记录时间，正文使用普通字体与细引用线。不同的录入原文仍可展开核对，正文为空时直接展示录入原文。AI 正文为 15px、行高 1.8，记录正文为 14px；原图保持原始比例、顺序和重复位置。主题颜色沿用当前选择。

记录来源样式归聊天模块 `record-answer.css`，交接模块的图片样式只负责共用原图与上传控件。固定版本引用及未引用候选不展开的规则继续保留。

## 实际模型与页面

在原普通用户会话中，用配置的 DeepSeek-V4-Flash 对原问题重新生成回复。最终耗时 20 秒，先直接回答温补试验精度与均值变化，关键时间及数值加粗，保留“记录人根据曲线判断”的归属；不再使用字段表单或添加适用性缺项说明。

Bugs Found：记录正文继承反馈区 12px 字号、AI 按字段重复正文，以及历史查询被强制追加条件缺项检查；本轮已修正。

Test Limitations / Untested Risks：真实模型仅验证本题，未批量评价所有问法；当前故障问答继续保留适用性核对规则，但本轮未新增真实供应商故障诊断用例。深色主题未单独做浏览器视觉验收，颜色沿用已有主题变量。

Test Quality：Medium。引用范围、完整文字、来源归属、全部原图及旧记录回退有自动化证据，实际模型与窄窗口显示已核对；不由单题结果推断所有模型回答质量。
