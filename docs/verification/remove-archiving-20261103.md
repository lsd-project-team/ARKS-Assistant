# 侧栏项目与对话归档清理（2026-11-03）

按用户要求移除“已归档”及其关联功能，侧栏只保留最近和回收站。交接资料、问题与经验的归档，以及消息历史档案、导出与备份保持各自职责。

## 实现范围

- 移除归档标签、项目归档及恢复菜单、对话归档操作、提示文字和搜索结果归档标记。
- 项目列表只请求正常项目；项目对话分页和最近搜索不再合并归档请求，管理员问题页和旧账号工作区迁移同步移除归档查询。
- 清理项目归档只读分支、输入框只读参数、相关样式、队列继续及新提问时自动恢复归档状态的逻辑。
- 项目和对话更新模型不再接收状态字段；归档查询参数由请求校验拒绝。回收站的删除、恢复、彻底删除及权限校验继续保留。
- 新增迁移 `0028`，仅将项目和对话的旧归档状态改为正常状态；不改更新时间、正文、归属、选区、引用、删除状态和暂停队列，不自动发送待发问题。
- 恢复浏览器状态时将旧归档视图及未知视图归一到最近，原草稿和阅读位置保留。数据库状态列继续承担正常及已删除记录的生命周期，不新增归档运行入口。
- 更新项目功能、使用指南、账号隔离说明及 `agent.md`。历史验收和迁移记录保留。
