## Bugs Found

新增测试自身曾有模型替身签名不匹配、Windows行尾预期错误、文件工具返回结构误用，均按实际契约修正，没有降低原件字节保持、真实补丁应用或错误状态断言。新增提示不应增加独立聊天的固定上下文负担；会话产物隔离增加的Windows长路径问题也已修复，原上下文压缩回归通过。
