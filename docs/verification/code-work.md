- 修改：临时数据库与真实独立文件副本；项目隔离、越界、硬链接和Windows目录联接；UTF-8、BOM、UTF-16大小端、GB18030与行尾保持。
- 补丁：真实 `git apply --check` 与 `git apply`，覆盖中文及空格路径、新文件、空文件、删除和无末尾换行；原件变化识别冲突，允许导出旧基线补丁留存，验证中禁止导出不稳定版本。
- 验证：真实临时Python命令的成功、非零退出、启动失败、完整日志和展示截断、超时、取消、关闭与服务重启。Windows Job Object覆盖挂起绑定失败、父进程先退出及服务进程异常退出后的后代清理。
- Agent：通过真实图执行确定性外部模型替身，先获得失败退出码和日志，再修改副本、重新验证通过；原文件字节不变。普通“继续”继承已授权修复；只解释、先讨论、否定修改的请求拒绝副本写入。
- 取消：使用线程闸门复现启动期及重复取消，验证启动登记后精确取消对应验证；晚到清理和异常保留，不误杀后来一次验证。
