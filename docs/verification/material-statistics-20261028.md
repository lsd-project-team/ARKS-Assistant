# 资料概况按文件类型统计

日期：2026-10-28。

按用户要求，概览保留资料卡片，采用与任务、问题经验相同的环形统计和列表联动交互。

- 按可见文件名扩展名分为PDF、Word、表格、图片、其他，显示总份数、各类份数和占比；原文件名优先于历史元信息及记录标题，不读取正文或解析文件。
- 图表、图例均可筛选下方资料；清除筛选和环形中心恢复全部，总份数不随筛选改变。零数量类型显示空列表，不生成假资料。
- 统计和列表共用有效资料范围，排除归档和非资料记录；历史文本、未知格式归入其他，按上传时间排列。下方每页2份，复用概览分页；点击资料仍打开原文件，查看全部进入资料页。
- 概览不恢复资料审核、修订展示或AI检索流程，不改正式资料与原件。
