# 侧栏拖拽排序、对话拖入项目与项目重命名

2026-11-13 按用户确认调整侧栏交互，拖拽方式对齐 DeepSeek Harness：使用浏览器原生拖拽和蓝色插入线。

## 行为

- 项目菜单「项目设置与重命名」改为「重命名」，弹窗只修改项目名称；源码目录只在新建项目时填写。
- 删除项目菜单的「向上移动 / 向下移动」，改为直接拖动项目名称。
- 项目拖拽只在置顶组或普通组内部排序，不允许跨组；拖动时显示蓝色插入线，松手后保存，刷新页面顺序保持。
- 最近对话可拖动：拖到项目上即移动到该项目，拖回「最近对话」区域即变为独立对话。
- 项目区对话不参与最近列表拖拽；短按项目名称仍是展开/收起，短按对话仍是打开对话。

## 接口

- 新增 `POST /api/projects/{project_id}/order`，请求体 `{"before_id": "..."}`；只重排当前账号、同一状态的置顶组或普通组，`before_id` 必须属于同一组。
- 对话拖入项目继续使用 `POST /api/projects/move-threads`，保留历史消息和源码引用。

## 验证

- 后端项目测试 35 项通过，包含新拖拽顺序、置顶组排序和跨组拒绝。
- 前端全量 419 项通过；`npx tsc -b` 与生产构建通过。
- 拖拽使用原生 `draggable` / `dragstart` / `dragover` / `drop`，与 DeepSeek Harness 的行拖拽方式一致。
- 未在真实浏览器中逐项手工拖拽验收；组件级测试未覆盖拖拽路径，发布前建议在桌面浏览器实际拖一次项目和对话。

## 边界

- 原生拖拽在移动端浏览器支持有限；本次按桌面交互实现，没有另做触摸长按。
- 拖拽不自动滚动侧栏，长列表拖到边缘时仍需先滚动到目标位置。
- 不支持键盘拖拽。
