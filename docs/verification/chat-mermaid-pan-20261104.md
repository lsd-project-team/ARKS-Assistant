# 聊天流程图左键拖动验收（2026-11-04）

聊天 Mermaid 流程图支持按住鼠标左键拖动查看，放大后可直接移动到需要阅读的位置。

## 实现与范围

`useDiagramPan` 管理鼠标指针捕获和图内横纵滚动，`MermaidViewport` 复用该 Hook，并显示左键拖动提示和抓手状态。普通 Markdown 与结构化 Mermaid 块继续共用同一组件，已有回复刷新后直接生效。

- 左键在图内按下后随鼠标移动滚动位置，使用增量位移；到达边界后反向拖动立即生效。
- 捕获指针后移出视口仍可拖动，松手、指针取消、捕获丢失、窗口失焦或检测到左键已松开时结束。
- 缩放、重置及组件卸载会释放旧捕获，后续鼠标移动不会覆盖新的图内位置。
- 右键、中键、非主指针、触屏和原生滚动条区域不进入鼠标拖动。图仍以清理后的 SVG 图片展示，保持原有 Ctrl＋滚轮缩放、普通滚动和源码查看。

未调整模型输出、业务消息、源码引用或后端接口。
