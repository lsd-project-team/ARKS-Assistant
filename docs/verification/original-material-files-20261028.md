# 原文件资料库验收

日期：2026-10-28。

用户确认的流程是“添加资料 → 选择文件上传 → 列表展示 → 点击查看原文件”。新增只保存原件，不提取内容、不进行 AI 分析或知识检索，不再展示确认、审核和版本流程。

## 实现范围

- 新增 /api/handover/sources/upload 保存原始字节、文件名、格式及 SHA256，最大 32 MB；空文件和超限文件拒绝写入。由服务端登录身份记录上传人，忽略请求中伪造的整理人及隐藏元信息。
- 列表显示文件名、实际上传人和上传时间，搜索只使用这些可见元信息。移除正文摘要、类型/状态筛选和归档开关；上传弹窗只保留文件选择、取消和上传。
- 资料详情直接进入原文件预览或下载，移除更新资料、正文提取、来源说明、源码快照选择、版本比较和审核入口。概览资料确认图表及审核队列中的资料分类也移除。
- PDF 使用固定版本 pdfjs-dist@6.4.299 绘制原页面并翻页，不调用文本提取；字体、CMap、ICC 及解码资源随应用本地发布。参考 [PDF.js 官方绘制示例](https://mozilla.github.io/pdf.js/examples/)。图片、常见文本直接显示原件，Word 等格式下载原件查看；HTML、SVG 等主动内容不内嵌执行。
- 预览、下载继续校验登录，原件响应禁止内容类型嗅探并限制其他站点嵌入。资料列表查询只补充附件名称和上传事件，不加载附件字节。
- 原数据库结构、旧文件、历史正文及固定引用保留；旧的纯文本记录仍可查阅或下载，现有兼容解析接口不用于新上传。未保存的旧本机草稿保持原存储，不再出现在新表单中。
