# 代码变更工具栏精简

日期：2026-11-06。

## 调整

用户标注了代码变更面板顶部工具栏，要求去掉重复功能。本次按实际入口去重：

| 原入口                                 | 调整与保留位置                                             |
| -------------------------------------- | ---------------------------------------------------------- |
| 刷新按钮                               | 移除；沿用每两秒状态轮询和写操作成功后的缓存失效           |
| 换行、左右/统一差异、全部展开/收起图标 | 收到“更多”，作用于所有展开文件；单文件仅使用文件标题折叠   |
| 验证状态图标与菜单“验证详情”           | 当前副本只保留状态图标；历史快照菜单明确标为“当前验证详情” |
| 验证运行时的执行与停止双按钮           | 执行/停止共用位置，运行时仅显示停止                        |
| “更多 → 让 AI 修改”                    | 移除；需求直接使用聊天输入框，选区反馈仍可带入草稿         |
| 文件标题复制按钮与菜单“复制路径”       | 移除标题按钮，保留文件菜单复制路径                         |

当前副本顶部从 8 个入口减少到 4 个：更多、验证状态、执行/停止和关闭。累计范围、历史快照、统计、逐文件差异、撤销、下载、合并、工程信息和管理员确认流程继续使用已有实现。没有改后端接口、正式业务记录或只读 trunk。
