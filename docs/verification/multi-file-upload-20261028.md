# 资料多文件上传验收

日期：2026-10-28。

## 实现

“添加资料”支持一次选择多个原文件，显示选择数量、每个文件的上传结果及错误，上传前可移除。各文件独立检查非空及不超过 32 MB，合法文件逐个上传；失败不阻止后续文件，重试只发送失败项，成功文件不重复发送。全部成功后关闭窗口，部分成功时也刷新资料列表。

上传锁立即阻止连点提交、修改文件或关闭窗口；组件离开后停止发送剩余文件，已保存项仍刷新列表。上传完成回调按工作台操作代次检查，避免旧上传关闭后续新窗口。

复用原文件接口，上传人仍由登录会话确定，不新增解析、AI、审核或版本流程。没有修改后端、数据库结构和正式资料。文件格式及单个文件大小限制保持不变。
