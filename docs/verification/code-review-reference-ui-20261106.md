# 用户截图参考的代码变更布局

日期：2026-11-06。

本轮以用户提供的 Codex 截图为直接视觉依据，沿用前轮已核实的静态 REA 结论，没有再次执行 Codex、复制其交付源码或把截图内代码视作任务指令。前轮静态分析范围、证据编号及限制见[精简验收](code-review-simple-20261106.md)。

## 实现

- 去掉独立文件侧栏和重复大标题，改为连续文件标题栏与内联差异；标题保留完整路径、真实逐文件增删数、复制和文件菜单。
- 顶部范围胶囊显示累计修改或历史轮次及其总增删数。历史按实际修订从新到旧排序并按运行编号去重，“上一轮”指最新真实轮次；没有轮次记录时只有累计范围。统计版本与当前文件不一致时隐藏旧统计。
- 图标工具条统一管理刷新、展开/收起、换行、左右/统一差异、验证详情、执行/停止验证及关闭。次级业务入口保留在“更多”。
- 默认左右对照，使用现有差异库的行内变化与未修改行分隔条。仅展开的文件发起差异读取，折叠后保留已加载视图和反馈输入；全局样式变更同步作用于已展开文件。
- 文件撤销移到对应文件菜单，确认保存点击时的路径和版本。修改块仍提交所查看的精确版本；修改期间通过共享 mutation key 阻止其他编辑和验证。历史不显示当前文件撤销或执行验证入口。
- 复用原工程权限、独立副本、恢复保护、管理员合并和聊天反馈逻辑，没有修改后端接口或正式业务数据。

拆分 `CodeReviewToolbar.tsx` 与 `CodeReviewFile.tsx`，布局样式在 `code-review-layout.css`；对话容器只负责范围、全局操作和页面协调。`ReviewDiff` 增加外部视图配置，合并预览继续保留原独立控制。
