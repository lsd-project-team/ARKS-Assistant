# 连续追问、旧用户消息筛选与运行概况验收

日期：2026-10-30。

## 变更范围

1. `agents/context/retrieval_context.py` 为记忆、经验筛选及最终经验核查提供当前有效分支在本题之前的有限背景：最多12条消息、6000字符，每条最多1200字符并标记截断，带项目名称和选区路径。记忆本地召回补入每条最多200字符的近期对象线索，最新纠正在前；没有新增问题改写或分类模型调用。重新生成的背景止于原问题，未来消息、被替换消息和其他聊天不进入。
2. `HistoryPlan` 将旧用户消息独立列为候选，模型必须保留持续要求、禁止项、未完成目标及更正/完成/取消状态。选中旧回复时程序自动带回对应问题，工具链保持完整；保留约束不必带上无关旧答复。近期六轮和受保护摘要段不变，原始消息和摘要不改写，原文回查继续可用。
3. `modules/chat/run_trace.py` 只从当前账号可见的保存事件汇总筛选数量、缓存、核查、模型请求和工具经过时间。`RunTraceSummary` 同时接入聊天内运行详情和上下文窗口，可打开记忆快照和固定版本经验原文。旧数据缺失不补零，失败不冒充无资料，各阶段重叠时间不相加。个人记忆统计及对应请求记录对其他账号隐藏。

没有数据库迁移，没有修改三句查询路由、资料来源开关或后台记忆生成规则，最终经验事实核查保留。
