# 左栏长标题渐隐验收

日期：2026-11-09。

## 实现范围

左栏对话标题保持单行，末尾 24px 使用透明遮罩渐隐。`ThreadItem` 根据真实 `scrollWidth > clientWidth` 标记溢出，只有溢出标题启用遮罩，短标题及刚好容纳的标题保持清晰。遮罩只作用于标题文本，不覆盖操作按钮、运行/置顶图标；透明遮罩沿用普通、选中、悬停及深浅色背景。

通过 `ResizeObserver`、标题/搜索高亮/选中/编辑状态变化及字体加载重新测量；退出编辑时重新观察，卸载或进入编辑时断开观察并清理字体监听，迟到的异步回调不读取旧元素。保持现有微软雅黑 UI、16px 主文字、13px 辅助文字、行高、列宽、行布局及完整标题提示，不改保存的标题、菜单行为、后端或数据结构。

CSS 位于 `sidebar-navigation.css`，溢出检测位于 `ThreadItem.tsx`。导航外不应用渐隐样式，品牌和项目名仍沿用原省略规则。
