# 长期记忆候选的模型适用性复核

2026-10-30，在本地相关性召回之后增加第二层模型复核。召回最多6条候选，向当前回答模型提供当前问题、候选原文、引用依据及已检查的源码状态；输出严格限制为候选编号列表，可以全部不选。程序按编号取回固定版本正文，模型不能改写或补造带入内容。

## 行为与边界

- 无候选、没有问题、无法装入预算、来源关闭或只读历史状态检查时，不调用筛选模型。
- 合法选择只允许属于本批候选的唯一字符串编号，最多6条；未知编号、重复、错误类型、额外正文等非法结构均停用本轮记忆。
- 每次输出最多512 token；长输入按完整条目分片，超长单条跳过；模型筛选总体限时30秒且不超过配置超时。失败或超时不回退未经复核的候选，正常回答继续尝试。
- 复用回答模型及现有项目额度回调，供应商实际用量单独记录为 `memory_selection`，未知用量不冒充零成本；额度不足仍遵守现有预算限制。
- 等待期间聊天内容、记忆发布版本、归属或源码状态变化后，不使用过期批准；组装时保留原有完整条目、适用条件和最终上下文预算约束。
- 仅选中正文、编号和来源进入运行快照，私人筛选事件对共享聊天中的其他账号隐藏。后台生成、完整记忆列表和原始业务记录不清空。

## Tested Areas

实际调用链验证筛选器看见两个同主题候选，而回答模型和运行快照只接收批准的一条；覆盖全部拒绝、错误JSON、未知或重复编号、错误类型、额外正文、输入分片、后续分片失败、超时、用户取消、归属变化、聊天改写或删除、发布版本和源码变化、额度记账与不足，以及共享账号可见性。数据库、原聊天、快照、上下文组装及Agent框架真实执行，远程模型用可控替身代替。

工作区曾在同期提示词重构期间暂时无法导入，未覆盖他人代码或重启坏版本；恢复后当前工作区3项问答链路检查通过。重启前正式库6条运行均已完成，已通过标准脚本更新本机服务，健康检查正常，数据目录仍为正式 `data/`。测试未写入正式聊天或记忆，也未调用真实供应商、MCP或设备；本轮无前端修改和构建。

## Test Limitations / Quality

质量判定为中等：协议、固定版本、权限、成本与失败边界已有反例及集成覆盖，但模型本身的适用性判断仍可能误选或漏选，召回遗漏也无法通过第二层恢复。尚未进行真实供应商对设备、版本、工况匹配的效果评估。显式验证脚本已更新为生成后调用真实筛选入口，本轮未执行该脚本。
