## Tested Areas

- **中文指令与恢复**：新增、删除、重命名、重构及“在隔离副本修改”进入实际工具流程；先讨论、先给方案、不要写代码与询问步骤不授权修改。“开始吧”仅续接此前用户明确请求；“继续”不解除临时讨论约束。要求通读并禁止改代码仍可启动阅读。真实Agent图覆盖读取、测试失败、修复、重新验证及原件字节不变。
- **需求与版本**：旧副本可补齐验收、约束及路径；修改需同时匹配源码和需求身份。约定变化使旧验证与审核失效。越界范围更新整笔拒绝；模型等待项目锁期间约定改变仍不能编辑，创建结果不能悄悄记住未展示的新约定。HTTP编辑和审核均要求需求哈希，旧窗口即使源码未变也不能审核新约定。历史记录与补丁保留，重新验证后可交付。
- **阅读新鲜度**：明确文件依赖传递失效；类型名、未声明依赖、模块成员变化及旧记录缺失快照时保守失效。真实临时SQLite覆盖循环、附加根、新增/删除文件与刷新前拒绝召回。声明依赖只标记declared_only，不能冒充静态完备。明确继续阅读先刷新快照，保留未受影响的进度。
- **Linux分析器准备**：平台可执行名、显式环境配置、本地工具、DOTNET_ROOT及PATH发现；无效显式配置不静默回退。正常问答不安装SDK；显式准备支持官方Windows/Linux脚本、固定新SDK版本及离线模式，只构建自带helper。跨平台命令契约使用临时文件和SDK边界替身；本机真实Roslyn调用及离线构建另行通过。
- **Windows执行**：Hyper-V、低权限目标、管理员监督ACL与独立TTL、物理盘容量及scratch预算、停止态复制、严格归档回传、超时/取消和精确清理。原生桥实际保留0/7/256/512/-1退出码；伪造JSON只成为base64日志。双流无换行洪泛受限，取消后Windows Job回收实际子进程；短引导器与有界stdin避免SSH默认cmd命令行上限。缺失证明、镜像/平台不符、伪协议与零退出码均不能混成通过。
- **模型质量入口**：18项独立回归复用真实服务、Agent、工具、SQLite及供应商回调，外部模型用确定性替身。原件哈希、引用版本、Git应用及反向回退均实际核对；报告固定源码、模型、应用和运行身份。凭据仅由明确环境变量进入内存；正式配置、历史对话和MCP不自动带入。机械通过仍是语义unknown，人工评审不能覆盖机械失败，报告改变使旧评审失效。

## Bugs Found

已修复：中文实施请求被误拒、讨论续接升级歧义、禁止写代码影响明确阅读、未知符号依赖被静默丢弃、旧摘要复用及完成任务不刷新、Linux硬编码dotnet.exe、旧副本无法补齐验收、需求变更后旧测试/审核可复用、编辑等待锁期间需求改变、创建结果记住未展示约定，以及Windows退出码经Linux低8位截断、桥命令长度超限和取消窗口仍启动执行。

更新新增版本契约时同步修改旧测试请求及前端夹具，没有把缺少版本的请求默认为当前值。测试还修正了Windows CRLF断言，以及供应商替身跨运行复用造成的重复回调；严格运行时警告检查通过。全量最终无失败。

## Test Limitations / Quality

没有真实Windows容器节点，Hyper-V、SDK/私有DLL、ACL及存储行为尚未现场验收；8项E2E明确跳过。Windows节点当前要求单服务、单进程专用，没有跨实例原子容量租约或进程数硬上限。TLS-only远端节点暂不能核对物理盘空间，会拒绝执行。

公司Linux服务器尚未部署，Linux分支未运行实际.NET SDK；Windows本机分析器成功不能代替Linux服务器验收。Roslyn基础引用来自分析器的.NET8，不能代替.NET Framework 4.8完整语义绑定。ZX2200未构建或运行，设备/工艺未测试。

未调用真实供应商。历史真实供应商报告存在，但不代表当前新增能力或当前模型质量通过；全仓模型通读、业务标准答案及人工评审仍待完成。未进行浏览器视觉验收。关键业务使用真实临时数据库、文件、Git、进程及Linux容器，并用失败反例验证边界；没有用整套Mock证明业务通过。
