# 回答来源统一显示在内容最后

日期：2026-11-01。

## 问题与变更

此前提示词把“来源”放到了正文末尾，但历史原图由 `KnowledgeFeedback` 追加，所以来源仍显示在图片之前。

本次由前端统一安排：正文和富内容 → 原图及反馈 → 来源。新回复、历史、流式、恢复和未完成回复使用同一展示组件。已保存的原消息不改写。

- Markdown按语法树收集真实来源链接，独立来源段移至页尾；行内链接保留标签文字。引用式链接、显式来源外链及无链接的来源说明继续支持。
- 富内容按白名单提取来源元数据，保留源码文件、行号、版本、目录身份；图表、代码和正文保持各自类型。
- 来源去重，代码/行内代码中的引用示例、损坏或未接收完整的协议不当作真实出处；未知块仍按原规则降级。
- 原图仍只跟随当前回答真实引用的记录及固定版本，保留原有顺序和重复图片。异步加载不改变来源位于图片之后的布局关系。
