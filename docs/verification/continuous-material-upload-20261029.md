# 资料保存后继续上传验收

日期：2026-10-29。

## 用户确认的流程

选择文件 → 上传保存 → 窗口保持打开 → 继续选择下一批文件 → 再次保存。用户完成添加后主动关闭窗口。

## 改动

- 移除整批成功后的自动关闭。保存成功显示提示，主按钮变为“继续选择文件”，直接打开原文件选择器。
- 分次选择追加到当前文件列表，保留已保存结果及未解决的失败项。下一轮只上传新文件和失败项，已成功文件不重传。
- 每轮成功后刷新资料列表，窗口继续保留。上传中仍阻止重复提交、修改文件和关闭，离开组件后停止发送剩余文件。
- 原文件接口、登录上传人、32 MB 单文件限制、预览和下载规则不变；没有修改后端、数据库结构和正式资料。
