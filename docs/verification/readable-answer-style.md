# 回答结构与阅读体验改进

日期：2026-10-19。接续[归纳与事实边界验收](grounded-answer-style.md)。

最新验证：本文保留此前排版修正的验证历史。最新15道经验、5道流程逐题测评见[20题实测](answer-quality-20.md)，两项同时达标8/20；不能用本文的定向测试代替最新整体质量结果。

## 问题与修正

用户确认回答已有自主分析，但参数、背景、解释和边界堆在长段落里，不便阅读。此前为了避免逐字段复述，系统提示、经验检索提示和复核规则过度限制小标题与列表；程序还把任意两个小标题或三个加粗列表项当作记录卡片，可能将清楚的回答改成长段文字，甚至降级成摘录。

本次统一调整三处规则：先简短回应重点，一段一个要点，多项参数、步骤和并列建议用列表，解释用自然段；必要时使用贴合内容的短标题。简单查询保持简短，不固定栏目，不给每段加标签，只强调少量关键词或数值。原文提取保留原文要求。边界说明随问题需要安排，不自动扩成设备、版本等缺项清单。

程序检查改为识别从源记录字段开始的卡片，正常的小标题、参数列表以及已有开头归纳的分组不会仅因排版形式被要求改写。语义上的归纳质量仍由模型复核与人工样本检查判断，正则不能理解回答内容。

针对实测中复核器漏判的排版问题，另向复核提供明确提示：连续48字以上的加粗、含数值且至少三个加号的连续组合、超过180字的连续正文段。代码、引文、链接目标不计入正文判断；原文提取与要求保留格式时跳过。阈值只是中文经验答复的可读性启发式，不等同于真实像素行宽或语义证明，不保证所有排版问题都能检出。修订仍需终审，格式问题不能靠返回 `passed` 绕过。

首轮经验复核同时检查阅读体验，修订不主动扩写新机理、风险或建议。保留固定版本来源、原记录人判断归属、组合与单项贡献的区别、原文保留、隐私和预算边界、修订稿终审及失败降级。只问能否推广时，资料不足就说明不能据此确定，不额外猜测其他工况。

视觉检查另发现单波浪号可能把同段的 `20~30g`、`280~300` 误解析成删除线。应用Markdown改为只有双波浪号 `~~文字~~` 才表示删除线，工艺范围原样显示，代码和原文文字不变。未修改 `trunk/`、页面字体或布局，也未写入正式账号、对话和经验数据。

## 真实模型与视觉检查

使用当前 DeepSeek-V4-Flash，沿用 `scripts/verification/answer_style.py --live`。只发送用户提供的蓝膜案例，使用临时数据库、空源码目录和同案例合成历史；新增 `dense_history` 场景验证长段旧答不会成为强制格式。真实调用消耗供应商额度。

调优中观察到：解除列表限制后，模型仍可能整句加粗、末尾堆边界说明；复核曾因字段标签把有归纳的答复改成长段落，也曾放过额外的工况机理推测。以上是实际缺陷，不能把复核器的 `passed` 当作人工验收通过。相应收紧了误判条件、强调简短边界和不主动扩写，最终样本另行核对。

本轮中间产物保存在本机 `output/answer-style-readable*.json`，包含应用源码哈希、实际回答、复核与用量。它们不作为正式业务记录。

最终结构检查接入后的 `output/answer-style-readable-verified.json`：主题回答和推广问法能经修订保留参数列表、短段与局部加粗，保留216颗及原始参数、原因归属和有限适用条件。长段历史场景有一次复核未返回有效结果，明确降级为摘录；重试保存于 `output/answer-style-readable-final-extra.json`，长段历史下已返回分项参数与归纳说明。调优中还有一次批次超时（`answer-style-readable-release.json`），部分结果保留，未计为整批通过。

上述最后两批共6次执行、5类问法：主题、推广、长段历史重试、完整原文4次正常返回；长段历史首次因复核结果无效降级，分析建议问法因两轮修订仍有格式及因果边界问题降级。这两次不算语言效果通过。原文场景完整保留四部分正文与原始参数，范围的波浪号也保留。分析建议类的正常生成质量仍不稳定，不能据此宣称所有分析建议都达到阅读与事实要求。

浏览器以应用相同的ReactMarkdown、GFM配置和经验展示插件渲染实际模型文本，正文样式沿用应用的字号、行高和间距，预览未写入正式对话。核对了参数分项、局部加粗、段落、范围数字与引用；该预览不能代替所有聊天宽度与题型验收。

## 限制与质量判断

表达优化依赖模型遵循规则，不能保证所有题型、历史上下文和供应商都达到相同效果。复核仍可能漏判；已有合格格式应保留，不为追求统一外观重复改写。未做真实设备测试、全业务语义验收或其他供应商对比。

测试质量：中。具备可复现误判、针对性反例、真实运行链路及当前模型样本；自动化能确认结构不会被规则误伤，语言质量与事实推理仍需持续人工检查。
