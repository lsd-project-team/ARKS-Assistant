## 实现范围

- 问题与经验可追加原图，PNG、JPEG、GIF、WebP 每张上限 8 MB，每条上限 100 处图片。
- 原图字节保存到 SQLite，修订保存有序引用。同图重复出现时保留每个位置，旧版本引用保持不变。
- 原图接口继承业务登录及 CSRF 校验，读取由记录、版本和位置共同定位，不能串读另一条记录的图片。
- 新运行检索问题与经验后，聊天显示命中记录的文字及全部原图；历史回看读取当轮固定版本。已排除的设备条件冲突记录不自动展开。
- 明确 adv-3、adv-10 等设备条件时分别筛选，工具改写查询不能抹去原问题的设备条件。
- 不调用图片识别，不提取截图数值，不上传或关联原始 Word。流程图谱、功能说明及交接资料仍暂停问答接入。

## 回答引用范围修正（2026年10月19日）

真实问题为“adv-3在7月23日09:00到7月24日16:30的试验结果是什么？展示记录文字和全部原图。”初版把自动检索候选都展开，导致同一回答展示四条记录和十二处图片；模型还从原始 JSON 中列出了图片哈希和文件名。

修正后，流式回复和历史回看都只展开回答实际引用的固定版本记录。候选中未引用的其他日期不展示，重复引用不重复展开；该记录内部三处图片完整保留，包括第二、第三处相同图片。明确要求多记录对照时仍按引用顺序展示。

模型的自动资料提示和读取、搜索工具仅返回中文业务文字投影、原图数量及可用的 Markdown 引用，读取工具保留完整原文；状态和类别使用中文含义，不返回图片哈希、存储文件名或来源关联字段。回答规则放在资料正文标签之外，要求围绕所问日期结束回答，由页面直接展示原图，不附加其他日期的建议或追问。正式记录和图片存储结构未修改。
