# 聊天扫描 PDF 与 ZIP 内扫描件 OCR 验收

日期：2026-11-06。

## 实现与读取边界

聊天 PDF 按页先提取现有文字，没有可提取文字的页面通过 PDFium 渲染，再用固定版本 RapidOCR 的中英文模型本地识别。直接上传、ZIP 内 PDF 和同时包含文字页/扫描页的 PDF 复用同一入口。文字保留页码、`[OCR 识别]` 标记及包内完整路径；识别失败页保留原因，低置信或缺失内容传播为整个 PDF/ZIP 的部分可读状态。OCR 后整份仍无文字时明确失败。

OCR 在独立子进程执行，避免 PDFium 线程并发问题，并可在超时后实际终止工作。每个附件累计最多 OCR 50 页，等待和识别累计最多 120 秒；ZIP 内多份 PDF 共用预算，累计超限拒绝整个附件。每个后端进程最多同时启动 2 个 OCR 子进程，渲染最长边最多 2500 像素，图像及 PDF 句柄及时释放。原有文件、压缩包及正文大小限制继续执行。

识别行低于 0.5 不采用；有被丢弃或低于 0.8 的有效识别行时标记部分可读。正文按识别行保存，不重建表格关系，也不解释图片。已有文字页内的嵌入图片和 Word/Excel 图片不另做 OCR。交接资料导入默认仍使用原文本解析，只有聊天显式提供 OCR 回调。

新增并锁定 `pypdfium2`、`rapidocr==3.10.0` 和 CPU `onnxruntime` 依赖。RapidOCR 所需模型随该发行版安装，显式使用安装包里的模型路径；缺失时提示重新运行 `Setup.ps1`，不会在解析文档时下载模型或调用云端视觉服务。未引入 Tesseract 系统安装、外部服务凭据或新数据库字段。

原始文件和提取正文继续按附件版本保存，下载返回原始文件。旧附件解析正文不自动重写，需要重新上传才会应用 OCR。测试和验证均使用临时数据库与资料，没有写入正式问答、附件或只读业务源码。

## 真实扫描样例与失败归因

样例 `backend/tests/fixtures/ocr/scan-zh-en.png` 由项目生成，包含“扫描文档测试”“设备参数：速度 120 mm/s”“测试结果：合格”及 `NewValue = 47`。测试通过 Pillow 生成仅含图片的 PDF，并先断言 pypdf 提取不到文字，再核对 OCR 输出，避免用隐藏文字层冒充识别成功。样例图已目视检查。

开发期反例检出 OCR JSON 非字典响应未正确降级，已修复并保留测试。实际 OCR 会改变字距，初版测试强制要求 `NewValue = 47` 的精确空格而失败，归因为测试预期错误；改为允许空格差异、仍精确核对参数名和数值，没有改写生产 OCR 正文。依赖选型后保留支持当前 Python 范围的 RapidOCR 3.10.0，临时验证的旧版及其 OpenCV 依赖未进入最终清单；本机替换 OpenCV 包造成的安装文件重叠通过重新安装最终 headless 包修复，最终锁定环境测试通过。

## 复现命令

在 `backend/` 执行：

```powershell
uv sync --frozen
.\.venv\Scripts\python.exe -X utf8 -m pytest -q tests/unit/chat/test_attachment_parsing.py tests/unit/chat/test_zip_attachment_parsing.py tests/unit/chat/test_pdf_ocr.py tests/integration/chat/test_attachments.py tests/integration/chat/test_attachment_access.py tests/integration/chat/test_pdf_ocr.py tests/integration/handover tests/architecture --tb=short
.\.venv\Scripts\python.exe -X utf8 -m pytest -q tests/unit/chat/test_pdf_ocr.py tests/integration/chat/test_pdf_ocr.py tests/integration/chat/test_attachments.py -k 'ocr or scan' --tb=short
uv lock --check
```

在 `frontend/` 执行：

```powershell
node --experimental-strip-types --test tests/chat/attachments.test.mjs
npx prettier --check src/features/chat/attachments/files.ts
npm run build -- --outDir ../output/pdf-ocr-release --logLevel warn
```

本轮不发布前端、不重启现有服务，不修改历史附件版本。使用方法及资源限制见[聊天附件](../features/chat-attachments.md)。
