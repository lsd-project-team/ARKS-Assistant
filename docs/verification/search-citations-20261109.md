# 搜索来源引用验收（2026-11-09）

## 变更与边界

按用户确认，仅修改前端源码引用解析与交互。本轮成功 `search_source` 的结构化命中，完整路径相同且命中行落在引用范围内时，来源使用现有绿色样式并可点击，不增加类别标签。搜索记录没有原始文件版本，点击定位当前源码；不把搜索命中登记为已读范围，不补造版本，也不增加模型调用、自动补读或回答后核查。

已读引用优先使用原规则。显式版本、已知版本变化、不可读和多个版本/来源冲突不能通过搜索降级。失败/跳过工具、工具参数、错误 JSON、相邻行、同名其他目录、非法路径或不一致身份不能启用引用。源码打开入口继续处理目录映射、项目切换、版本和当前行范围；后端及权限 API 未修改。
