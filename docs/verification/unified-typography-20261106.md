## 范围与依据

用户在确认 AI 回复和左栏字号后，要求其余界面统一，并明确同意开始实施。采用正文 16px、控件 14px、辅助信息 13px、代码 14px、表格 15px，以及页面/区块/弹窗标题 22/18/20px。角色和维护规则见[全站字号层级](../features/typography.md)。

各模块原有字号声明改为引用公共变量，保留主题、选择器与按需加载边界。源码默认字号从 12px 升到 14px，并迁移旧默认值；用户其他自定义字号、升级后主动选回的 12px、草稿与阅读位置保留。实际浏览器检查发现窄栏变更摘要标题受挤压，以及旧主题选择器覆盖阅读页标题，已分别增加容器适配并统一相关标题声明。
