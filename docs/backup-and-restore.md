# 本地备份与恢复

设置 → 数据可以查看对话、记忆、原文档案、导出备份和恢复旧数据的占用，以及数据库版本和磁盘剩余空间。

## 导出与预览

完成或停止当前回复后选择“导出本地备份”。ZIP 包含业务数据库、Agent 检查点、记忆文件和原文档案；`settings.private.json` 密钥配置不进入备份。新格式 v1 的 `manifest.json` 记录文件大小、SHA-256、数据版本和记录数量。

“选择备份并校验”只在本机隔离目录检查所选 ZIP，展示恢复预览，不替换当前数据。检查包括 ZIP 完整性、路径边界、文件清单、哈希、SQLite 完整性与外键、已知迁移版本。旧格式没有哈希清单时仍检查 ZIP 和数据库，并明确显示旧格式提示。不支持超过 512 MiB 的 ZIP、超过 2 GiB 的展开内容、加密 ZIP、未知格式版本或未知数据版本。

## 停服恢复

在项目目录运行以下命令；备份路径可以包含中文和空格。

```powershell
# 仅校验，不替换文件
.\scripts\RestoreData.ps1 -Backup 'D:\备份目录\trunk-agent.zip'

# 停止服务，确认预览后恢复，再启动
.\Stop.ps1
.\scripts\RestoreData.ps1 -Backup 'D:\备份目录\trunk-agent.zip' -Apply
.\Start.ps1
```

运行中的服务持有数据目录锁，恢复工具会拒绝替换。需要恢复到另一个数据目录时传入 `-DataDirectory 'D:\新目录\data'`；启动程序时应使用相同的 `TRUNK_AGENT_DATA_DIR`。

恢复先在同一磁盘校验和暂存，再移动对话数据库、检查点、记忆与档案。现有密钥配置保留。被替换的旧文件保存在返回结果中的 `.restore-recovery-…` 目录，供核对和人工恢复；不要在确认恢复结果前删除。旧备份的已知数据库版本会在正常启动时迁移到当前版本。

## 失败与中断

普通文件替换失败会自动归还旧文件。断电或进程被终止可能留下 `restore.pending.json`；程序启动会拒绝使用半恢复的数据。先执行：

```powershell
.\scripts\RestoreData.ps1 -Rollback
.\Start.ps1
```

回滚把未完成的新数据移到恢复目录的 `rejected` 子目录，并归还旧数据。回滚工具也需要服务已停止。成功完成的恢复没有待恢复日志，`-Rollback` 仅用于未完成的恢复。

## 会话整理与单会话导出

会话菜单可导出 Markdown；API `/api/threads/{id}/export?format=json` 返回 `schema_version=1` 的完整原始会话和选区。

会话侧栏的“整理空会话”先展示预览，只选择没有消息、运行、等待问题和来源记忆的未置顶会话。当前窗口有未发送草稿的会话不可选择。执行时重新检查空会话条件和预览版本；任一会话已变化时整个批次不执行。整理结果进入回收站，可通过轻提示撤销或逐个恢复，不自动清理历史记录。
