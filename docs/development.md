Windows 本机使用，浏览器访问；React / TypeScript / Monaco；FastAPI / Deep Agents；兼容 OpenAI 的可配置模型接口；SQLite 会话和检查点；文件长期记忆；DeepWiki MCP；源码阅读问答与普通聊天；多轮对话、跨会话记忆和自动上下文压缩。

源码根目录默认为 `trunk`，应用放在其外。编码遵循根目录 `SKILL.md`。首版实现源码阅读和问答，代码自动修改与执行构建属于后续扩展。

## 数据边界

- workspace_id：源码和项目记忆的范围。
- thread_id：一条会话及其 Agent 检查点。
- run_id：一次执行；中断恢复保留原消息，不重复提交用户问题。
- 选区：文件路径、起止行号、内容快照、SHA-256 文件版本。
- 业务数据库保存原始消息与运行事件；检查点数据库保存 Agent 工作状态；记忆目录保存长期笔记。
- 同一会话最多一个活动运行。写数据库使用短事务；SSE 从持久化事件序号重放，浏览器断线不取消任务。

## 界面设计

浅色三栏代码工作区：左侧文件 / 会话，中间代码，右侧对话。参考用户截图，以真实文件路径和选区为核心。

颜色：背景 #f7f8fa，面板 #ffffff，文字 #202833，次级文字 #77808d，边线 #e5e9ef，强调色 #326baf。
字体：中文系统字体与 Segoe UI；代码使用 Cascadia Code / Consolas。选区引用卡是主要交互标识，显示文件与行号，可跳转。
布局采用可调宽度分栏；窄屏切换源码与对话视图。避免营销内容和装饰性统计。
