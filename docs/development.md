## 数据边界

- workspace_id：源码和项目记忆的范围。
- thread_id：一条会话及其 Agent 检查点。
- run_id：一次执行；中断恢复保留原消息，不重复提交用户问题。
- 选区：文件路径、起止行号、内容快照、SHA-256 文件版本。
- 业务数据库保存原始消息与运行事件；检查点数据库保存 Agent 工作状态；记忆目录保存长期笔记。
- 同一会话最多一个活动运行。写数据库使用短事务；SSE 从持久化事件序号重放，浏览器断线不取消任务。

## 界面设计

按用户最新截图重排：左侧会话导航，问答在左，源码工作区在右，文件树位于源码区最右侧。编辑器文件标签与会话标题处于同一高度，以真实文件路径和选区为核心。

按用户要求停止使用 `frontend-design` 技能，直接参考 Codex 截图使用黑白灰、轻分隔线、黑色用户气泡和圆角输入框，移除 Agent / 框架徽章。正文提高字号与对比度，中文系统字体与 Segoe UI；代码使用 Consolas 等宽字体。选区卡显示文件与行号，回复引用支持跳转。

问答宽度可向右拖动扩大，也可通过分隔线的方向键调整；文件树独立收起。中等窗口优先保留左右双栏，会话导航以浮层展开；800 像素以下才切换问答与源码视图。启动页直接展示实际源码和对话，不加入营销内容。

本轮 UI 验证：前端构建和格式检查通过，浏览器实测桌面、1440 像素宽屏、520 像素窄屏及当前约 900 像素窗口。已验证源码引用跳转、拖动分栏、方向键调整、代码选区加入问答、会话搜索、文件树收起和导航浮层。
