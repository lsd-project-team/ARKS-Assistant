## 判定规则

1. 同一模块的上下文图、目录图、类型关系图和主流程图，只保留一个总览入口。
2. 按钮处理器、异常分支、状态机、坐标算法和落盘细节可以保留为专题图，但必须从主入口进入。
3. 静态源码说明不再使用“全景与流程图”作为标题，避免与动态图谱争夺入口。
4. Mermaid 图和 ASCII 版表达同一内容时，只保留 Mermaid 版；ASCII 版只在确实提供额外文字信息时保留。
5. 删除图前先检查图号、节点链接、旧 URL 和目录索引；已发布的旧链接先指向归并后的主图。

## 当前结论

目前扫描到的重复主要是“同一业务的不同层次表达”，不是大量完全相同的 Mermaid 图。已确认可以直接删除的重复图是 43 号中的料单元上下文图；其余图先保留，通过入口分层消除重复感，待逐图核对引用后再合并。
