# 功能与流程图谱归并清单

2026-11-11，按用户确认的清单，将 20 组重叠图谱归入同一阅读页。目录从 121 个入口收敛为 **77 个入口：8 条生产主流程、69 个深入阅读入口**。原 121 张图全部保留，44 个细节入口通过所属主图中的选择器打开。

## 阅读方式

- 目录顶部恢复“系统与流程”展示卡，左侧说明生产全局，右侧展示阅读路线；筛选区继续服务图谱目录，避免再出现独立专题式介绍块。
- 进入目录默认打开主图，页内“查看图谱”选择器可切换主图与细节图，任一时刻只显示一个画布。
- 原图的节点、分支、说明、公式和表格保留。各原图仍使用自己的资源和阅读内容，数量或业务边界表述没有被另一张图覆盖。
- 搜索同时覆盖主图与细节图的名称、编号和原搜索内容。命中细节时卡片标明匹配图，点击直接选中该图；图谱类型也按实际命中的成员筛选。
- 相关图谱按合并后的入口去重，不再出现本组成员的重复卡片。
- G0 与产品坐标、相机标定与工具校准及全局标定、S2 调度与取晶及固晶动作分别保留独立入口。

## 兼容与维护

归并清单位于 `frontend/src/features/knowledge/data/graphCollections.ts`，目录搜索及关联阅读由 `graphDirectory.ts` 统一处理。每张公开图仅有一个主入口归属，不允许重复归属或嵌套归并。

旧 `#graph/<id>`、`#catalog/<id>` 地址仍进入原图；归入主图后使用 `?view=<原图id>` 保存选中状态，刷新、后退和前进可恢复。信号和旧章节参数继续保留，非法或跨组的 view 回到当前主图。原 23 个专题链接同样保留内容定位，专题页面及入口继续关闭。

此轮归并的是目录和阅读页入口，保留全部原 HTML、Markdown 和图谱资源，不恢复独立文档阅读器。验收见[图谱归并验收](../verification/graph-merge-20261111.md)，前一轮专题移除见[历史验收](../verification/graph-only-20261111.md)。
