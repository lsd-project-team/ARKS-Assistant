# 独立对话的默认源码能力

独立对话使用默认公司源码。查看流程图谱、功能说明和点击同一源码目录的引用，与使用该目录的项目对话采用相同逻辑；项目记忆仍按原项目和账号保存，不复制到独立对话。项目说明、项目指令及其数据库字段已移除，项目资料和全项目阅读也已退出AI问答。

## 页面与来源身份

受登录及项目归属检查保护的 `GET /api/projects/{scope_id}/source-context` 返回真实主源码身份、附加源码身份和资料可用性。独立对话使用 `independent`，不假造项目资料。前端按 scope 缓存，改绑目录后随项目缓存一起失效。首次加载和加载失败分别显示等待、错误与重试，不把尚未加载解释成没有资料。

独立对话可以查看默认源码对应的流程图谱、功能说明及原图。其他源码项目仍按实际目录判断资料是否匹配，不把 ZX2200 的资料显示为任意项目的资料。页面访问与 AI 问答来源分开控制；先前暂停的流程图谱、功能说明和交接资料自动检索保持暂停。

## 源码引用

点击引用前先获取真实来源身份，当前主目录和已关联目录的引用在右侧源码阅读器打开，核对版本并定位行范围，代码树展开到对应文件。附加目录的旧相对路径会补上目录身份前缀，防止跳到主目录的同名文件。等待元数据或文件时切换了项目，就取消本次界面更新。

当前目录与历史引用确实来自不同来源时仍按原始来源只读核对，不将其错误打开成当前目录文件。来源身份读取失败也不绕过权限或猜测目录。

新回答中，多行源码引用的显示范围和链接范围必须一致。旧回答只有起始锚点时，仅在标签的文件名、起始行一致，并且本轮保存的读取证据覆盖整个范围时恢复结束行；缺少证据时保留链接明确提供的范围。打开时仍校验当前文件版本和实际行数，失效引用打开当前文件并提示重新定位。
