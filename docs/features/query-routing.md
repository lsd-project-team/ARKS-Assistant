# 问题识别与查询路由

2026-11-06 更新：回答生成后不再进行源码引用校验或历史经验事实复核，不自动追加“注意”或把经验引用改成“资料引用未核对”。生成前的资料相关性筛选继续保留。

2026-10-30 起，开启“问题与经验”只表示允许使用对应工具，不再让每个问题都自动搜索问题库。主模型先结合当前问题和对话前文，判断是否与当前项目相关。

| 判断 | 路径 |
| --- | --- |
| 与当前项目无关 | 直接回答，不检索项目源码或问题与经验 |
| 项目故障处理、调参、历史办法 | 优先查询问题与经验 |
| 当前代码实现、执行流程、分支、程序参数定义 | 优先读取源码 |
| 同时询问工艺经验和软件实现 | 分别查询所需部分，按各自依据回答 |

2026-11-01，补齐“是否足够回答”的停止规则：结果已支持当前问题的主要答案时直接回答，不为凑齐来源补查。信息不足时，仅围绕影响答案的具体缺口查询其他可能有用的来源；可用来源仍无法支持的部分明确无法确认，不编造。资料不足不影响与项目无关的日常问题正常回答。

普通问题不再通过“设备词＋怎么/如何”或“方法”等关键词强制读取源码。主模型的本轮工具选择决定是否启用源码专项阅读规则；选区、深度分析和继续分析的明确要求保留。重新生成时仍只复用同版本、同目录的历史已读片段。

模型使用足以支持本题的依据生成回答，不因曾查询过未采用的源码而被程序要求补充引用。混合问题可分别使用经验和源码，生成后不再调用另一轮来源检查或事实核查，也不为核查构建完整记录或源码上下文。

这通常称为**意图识别**或**查询路由**，当前提示词只判断与项目相关或无关。没有增加固定关键词白名单，也没有在每个问题之前额外调用一次分类模型。主模型第一次响应可以直接给答案，也可以提出工具调用；检索、记录加载和核查只在需要时发生。较长回复的续写和长对话压缩仍可能增加模型调用。

## 运行与来源

“问题与经验”关闭时不提供对应查询工具；开启时只装配工具定义，问题库快照延迟到第一次查询或按编号读取时建立。同轮后续调用共享该快照，避免检索和读取混用不同版本。并行工具调用只建立一份快照。

检索得到候选后，先在工具内部单独调用模型，按当前问题的设备、日期、阶段和事项选择相关原文片段。筛选只返回记录与片段编号，程序从同轮固定版本取回原文；候选正文和未选中的标题、引用不会进入回答模型的工具结果。无候选时不调用筛选模型；同轮重复读取已经筛选过的版本复用结果，并行调用共用缓存。

搜索和按编号读取都经过这个边界；追问需要原记录时，可由模型直接按已有编号读取并重新筛选，无须重复相似度搜索。筛选失败、超时、协议无效或输入超限时不回退候选原文，工具明确说明处理未完成。有效筛选的空结果则只说明本轮没有选中适用内容，不能据此宣称全库没有记录。普通问题被判为不依赖历史记录时仍可正常回答。

回答模型根据选定内容直接生成答案。源码和经验类回答同样正常流式输出，保留输出完整度处理及展示协议语法检查；结束时仅在需要同步实际最终正文时发送替换事件，不再等待来源复核。

新运行不再生成 `answer_validation`、`knowledge_answer_check`、`knowledge_answer_review`、`source_review` 或 `answer_review_note` 等回答后核查事件，不给新回答登记“引用核查通过”。历史回答及原核查事件保持原样，既有查看入口继续兼容。

源码读取时的路径范围、实际文件版本、账号与项目权限继续由工具和接口校验，副本编辑、编译与仿真也保留各自的版本及执行约束。这些访问和执行边界不属于已移除的回答后检查。模型输出的引用继续按原展示协议渲染，原来源记录和页尾布局保留。

经验匹配状态和缺项只供内部判断，不要求用户逐项核对设备、版本、模块和工况，也不在答案末尾追加泛泛的历史经验或现场验证提醒。生成阶段只保留会改变处理办法、参数或适用范围的具体条件，紧邻对应内容且只说一次；如参数单位未知或存在明确条件冲突，须说明具体影响。复核不重复已说明的条件。匹配筛选仍保留冲突原因，不将条件不符的记录当作当前可直接套用的方案。

经验专用规则在启用该来源时进入系统提示一次，搜索和按编号分页读取不再重复返回整段 `display_hint`。通用回答表达与来源位置由主提示负责；经验提示保留匹配字段、历史状态、原图及引用协议规则。资料筛选仍可能增加模型调用，回答后的独立事实核查调用已经移除。

“上下文”和运行档案只为本轮筛选后实际提供的记录登记来源，检索候选和未选中记录不冒充已带入。旧运行的自动带入快照继续按原档案显示；没有重写历史对话或历史工具结果。

账号全局 `agent.md`、当前对话历史和长期记忆沿用各自设置；本次没有改变记忆生成、账号权限、项目隔离或已有记录。普通问题仍可使用账号的回答偏好。

工具权限、上下文预算、读取来源记录和运行档案继续保留。早期路由验收见[查询路由验证](../verification/query-routing-20261030.md)，当前回答后核查移除见[本轮验收](../verification/remove-answer-review-20261106.md)。

连续追问的记忆与经验筛选共用当前有效分支在本题之前的有限近期对话、项目名称和选区路径。背景最多12条消息、6000字符，每条最多1200字符并标记截断；不复制整块选区，不带入其他聊天或重新生成位置之后的消息。记忆本地召回也补入近期对象线索，筛选仍以当前明确问题和最新更正为准，切换话题不沿用旧对象。不增加独立的问题改写模型调用。运行过程见[回答依据与耗时](run-evidence-trace.md)。
