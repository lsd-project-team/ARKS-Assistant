# 问题识别与查询路由

2026-10-30 起，开启“问题与经验”只表示允许使用对应工具，不再让每个问题都自动搜索问题库。主模型先结合当前问题和对话前文，选择直接回答、查询历史资料或读取当前源码。

| 问题 | 默认路径 |
| --- | --- |
| 你好、介绍 Vue、一般概念、翻译或改写 | 直接回答，不加载和检索问题库，不调用经验筛选与事实核查 |
| 查询历史处理经验、报警记录、特定日期试验或原图 | 按需调用问题库搜索和记录读取，再筛选并核对事实与引用 |
| 当前项目源码、设备具体实现和流程 | 使用源码工具读取当前实现，按问题需要补查历史经验 |
| 追问前文已经读过的记录 | 可复用前文；实际引用时按编号核对版本并执行事实核查，必要时再搜索 |

这通常称为**意图识别**或**查询路由**，本次实现专门判断资料需求。没有增加固定关键词白名单，也没有在每个问题之前额外调用一次分类模型。主模型第一次响应可以直接给答案，也可以提出工具调用；检索、记录加载和核查只在需要时发生。较长回复的续写和长对话压缩仍可能增加模型调用。

## 运行与来源

“问题与经验”关闭时不提供对应查询工具；开启时只装配工具定义，问题库快照延迟到第一次查询或引用核对时建立。同轮后续调用共享该快照，避免检索、读取和核查混用不同版本。并行工具调用只建立一份快照。

检索结果是候选。历史查询没有匹配时不能用通用知识补造记录；复用前文引用也必须核对该编号和版本，不能仅因已经聊过就跳过事实约束。记录已经变化或不可用时保守报告核对未完成。

“上下文”和运行档案按工具实际返回、或引用核对实际读取的记录显示来源，不把开启来源当作已检索。旧运行的自动带入快照继续按原档案显示。

账号全局 `agent.md`、当前对话历史和长期记忆沿用各自设置；本次没有改变记忆生成、账号权限、项目隔离或已有记录。普通问题仍可使用账号的回答偏好。

模型可能误判是否需要工具。工具权限、上下文预算、源码证据和经验事实核查继续保留；路由选择不是事实验证。实际验收见[查询路由验证](../verification/query-routing-20261030.md)。
