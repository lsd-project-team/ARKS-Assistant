# 问题与经验的文字和原图

问答通过原文已有的文字检索问题与经验，在回复下方展示回答实际引用记录的正文及对应原图。图片按记录中的顺序完整显示，相同图片多次出现时保留每一处位置。图片可以点开查看原始大小。

图片不做 OCR、模型识别、数值抄录、裁切或重绘，原始 Word 不作为附件关联。模型依据文字回答，不能声称已经分析过原图。纯图片记录依靠标题、日期等已有文字检索，不从图片推断设备、条件或结果。

## 保存与查看

在“交接工作台 → 问题与经验”打开记录，通过“添加原图”按顺序追加图片。每张图片最大 8 MB，支持 PNG、JPEG、GIF、WebP，每条记录最多保存 100 处图片。记录编辑会保留已经关联的原图。

图片字节存入业务 SQLite，跟随现有备份和恢复流程。每次追加原图都会生成新修订；聊天引用固定版本的正文和图片，后续编辑或新增图片不会改变旧回复对应的原图。记录归档后不进入新的检索，已存在的固定版本引用仍可回看。

## 问答范围

检索引用携带原图数量，页面只读取回答明确引用记录的固定版本。仅作为候选返回、未被回答引用的其他日期记录不会展开；流式回复和历史回看使用相同筛选规则。同一记录的重复引用只展示一组正文和原图，组内重复图片仍完整保留。用户明确要求多记录对照时，按回答中的引用顺序展示各组。

模型读取记录时只获得中文业务字段、原文、原图数量及固定版本引用，状态和类别转换为中文表述，不提供图片哈希、存储文件名和来源关联字段。回答使用记录事实和引用，不列图片ID、内部字段或枚举清单。原图由页面展示，模型没有识别图片不影响原图加载。

该能力沿用“知识资料”开关中的“问题与经验”来源，不重新启用流程图谱、功能说明或交接资料检索。
