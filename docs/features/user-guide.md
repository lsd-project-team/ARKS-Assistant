# ARKS 智能助手使用指南

本指南介绍日常对话、源码阅读、资料问答和调试经验保存。首次安装和模型连接步骤见[项目首页](../../README.md#快速开始)，运行问题见[本地运行与开发](../development/local-development.md)。

## 账号与项目

管理员使用独立管理工作区，负责账号、系统配置、问答记录、交接复核和数据维护。普通用户进入日常问答与交接工作区，通过右上角账号菜单退出或访问 `/#login` 切换账号。

个人项目、对话、项目资料、指令和记忆按账号隔离；公司交接资料与调试问题库继续共享。管理员保留管理访问权限。完整范围见[项目与对话隔离](account-workspace-isolation.md)。

在侧栏选择已有项目，或在“项目”旁新建项目。项目可关联源码目录、资料和回答指令；不需要项目归属时，可从顶部“新对话”开始独立对话。公司源码已由管理员配置时，新账号的默认项目会自动关联该源码。

源码目录、DeepWiki 仓库和可用的功能资料随项目切换。项目资料导入、附加源码目录、对话移动、归档及导出，见[项目功能](projects.md)。

## 对话与历史

- **发送问题**：Enter 发送，Shift + Enter 换行。已有对话从侧栏打开。
- **查找历史**：点击侧栏搜索图标，搜索标题、正文或代码选区；命中正文后可以直接定位。搜索范围随最近、归档或回收站页面切换。
- **处理回复**：回复可复制；最近完成的回复支持重新生成，并保留原问题、选区和旧版回复。失败可重试，停止后可继续。
- **恢复阅读**：输入草稿与代码选区按会话保存。流式回复时向上阅读历史不会被拉回，点击“回到最新”恢复跟随。

网络断开不会自动取消运行，重新连接后可重放已保存的运行事件。同一会话串行执行，全局最多同时进行三个运行。

聊天输入框的加号目前仅预留为上传入口；共享工作资料在“交接工作台 → 资料”维护。

## 功能与流程

侧栏的“功能与流程”统一提供功能说明和流程图谱。首页按业务环节展示功能专题，进入专题后可查看说明、关联流程图和源码入口。

需要直接找图时，点击首页的“全部图谱”，按名称、专题、阅读层级或类型筛选。图谱列表可返回“功能与流程”，阅读图谱或专题时侧栏保持同一入口高亮。已有专题和图谱链接仍可直接打开。

## 阅读源码与提问

1. 在右侧文件树单击文件进行临时预览，双击保留标签；也可以按 Ctrl+P 搜索文件名或路径。
2. 在编辑器中选中代码，点击“将选区加入对话”，再输入问题。引用会保存文件、行列、内容快照和文件版本。
3. 点击回答中的源码引用，跳转到对应位置。工具调用可以展开，查看本轮读取和分析过程。

Markdown 文件默认预览，可从顶部切换到源码；预览中的选区会对应原始文件行号。代码块可直接复制。

顶部提供复制路径、前进后退及文件树开关，Alt + 方向键也可导航。“更多文件操作”提供重新读取、自动换行、保留标签和关闭其他标签；文件树支持定位当前文件与全部折叠。

对话、源码区和文件树之间的分隔线可拖动或用方向键调整。布局、阅读位置、目录展开状态与文件树滚动位置会保存；顶部“工作区”可统一展开或收起源码区和文件树，窄屏也可切换。

源码保持只读。C# 分析优先使用 Roslyn 核对重载、调用者和接口候选实现；缺失依赖或无法确定的关系会显示未知，备用 Tree-sitter 在独立子进程解析。分析工具不会构建被分析的业务项目。

## 资料与知识问答

项目首页保留“对话”和“代码工作”；源码关联、项目说明和项目指令在“项目设置”维护。已有项目文档和共享结论仍可检索，管理员在“系统配置 → 项目资料与共享结论”维护；共享工作资料在“交接工作台 → 资料”维护。支持的文件格式、大小限制和版本行为见[项目功能](projects.md)。

在“设置 → 知识来源”选择需要使用的来源：

- **DeepWiki**：访问当前项目关联仓库的外部资料。创建项目时会尝试识别源码目录的 GitHub 远端；无法识别时可手动填写仓库。
- **知识资料**：检索问题与经验、项目文档、共享结论和项目阅读成果。流程图谱、功能说明和交接资料暂不接入 AI 问答，页面及已有数据保留。
- **长期记忆**：使用已保存的个人偏好或当前项目事实。

也可以只使用本地源码。来源选择按项目保存，独立对话单独配置。新问题和新加入队列的问题使用新配置；历史问题、重新生成和已经排队的问题保留原配置。

回复的“本轮参考”和“上下文”显示实际带入的资料、源码证据、复核状态及供应商实报用量。资料引用使用保存的真实标题和固定版本；资料更新后，旧回答仍可查看原引用版本。引用位置有效并不代表结论已经通过人工或设备验证。

本机检索支持关键词、同义词和语义匹配。语义模型缺失时会提示降级，正常问答期间不会自动下载该模型。接入与检索范围见[对话知识优化](chat-knowledge-improvements.md)。

## 保存与复用调试经验

可以通过两种方式登记调试问题：

1. 打开“交接工作台 → 调试问题 → 记录调试问题”，填写现象、发生条件、排查过程和已知的处理结果。
2. 在对话中输入 `/记录问题`，后接实际调试描述；也可以从 `/` 命令菜单选择“记录调试问题”。

对话录入会按原文整理，保存成功后进入同一个问题库，并保留原始描述、录入人和来源。普通聊天不会自动将全部内容录库，未填写的原因或处理结果也不会由 AI 补成事实。

再次询问类似故障时，开启“知识资料”来源，并尽量说明设备、版本、模块、报警码和发生条件。检索会核对这些条件；未解决记录和条件不同的历史记录用于对照，不能直接作为已经验证的处理方案。

交接工作台还可维护共享资料、任务进度与交接包。业务流程和版本规则见[交接工作台](handover-workbench.md)。

## 长期记忆与上下文

在“设置 → 长期记忆”查看、编辑和删除项目事实与个人偏好，查看更新时间或跳转到来源对话。个人偏好按账号隔离，项目记忆用于所属项目；源码变化后，对应记忆会标记为需核对。记忆还支持待复核、失效和历史恢复。

输入框底部显示估算的上下文用量，点击可查看资料和压缩摘要。回复旁的“上下文”显示本轮实际带入的记忆版本与资料记录。

| 操作                 | 用途                                           |
| -------------------- | ---------------------------------------------- |
| 输入 `/`             | 展开命令列表；方向键选择、Enter 执行、Esc 收起 |
| `/context`           | 查看对话上下文详情                             |
| `/compact`           | 请求压缩当前上下文                             |
| `/记录问题 调试描述` | 整理并保存调试问题                             |

上下文接近容量时会自动压缩，输入框附近显示进度、完成或错误；内容过短时工具会说明无需压缩。可以在“对话上下文”纠正摘要，纠正结果用于后续回复，原始消息仍然保留。

## 模型设置与数据维护

模型配置由管理员维护，支持 OpenAI Chat Completions 和 Anthropic Messages 协议。可填写服务地址、模型、密钥、上下文容量及可选的压缩模型；DeepWiki MCP 使用 Streamable HTTP。

普通用户可在对话输入框下方切换管理员已配置的模型。选择按账号保存，刷新、重新登录后保留，各账号互不影响；运行中的回复继续使用原模型，下一轮使用新选择。管理员删除已选配置时，自动回退到系统默认模型。

应用数据保存在本机 `data/`，使用外部模型时会向所配置的模型服务发送本轮需要的上下文。DeepWiki 查询也会访问外部服务。

管理员可在“数据维护”导出备份；备份不包含 API 密钥配置。恢复前必须停止服务，完整步骤及中断处理见[本地备份与恢复](../development/backup-and-restore.md)。
