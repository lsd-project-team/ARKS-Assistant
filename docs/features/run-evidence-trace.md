# 运行依据统计与展示状态

生成答案前仅由助手名称旁显示运行状态与计时，正文不再重复显示“正在思考…”占位文字；错误反馈、答案与引用照常展示。

2026-11-01，生成期间与历史回复共用默认收起的“运行详情”。生成期间的工具调用不再直接铺开；工具状态及答案更新不改变用户手动选择。每次新运行默认收起，没有可展示详情时不显示空折叠区。只调整前端展示，不增加查询、模型调用或修改事件记录。

2026-10-30，用户反馈新增“本轮依据与耗时”内容过多，随后明确要求去掉。当前已从聊天运行详情和上下文窗口撤下整块展示，删除专用组件、样式、类型和展示测试；运行详情恢复新增前的工具活动与分析进度，取消为概况新增的上下文请求及定时刷新。

原有回答耗时、资料引用及上下文入口继续保留。连续追问语境、旧历史筛选、记忆与经验筛选、最终事实核查和后端事件记录不变，没有改动原始消息、摘要、记忆或资料，也不需要重启后端。

本次撤下的是界面展示；后端按账号可见事件汇总的统计仍保留供排查，不新增模型请求。旧实现及验收情况见[原验收记录](../verification/context-trace-improvements-20261030.md)。
