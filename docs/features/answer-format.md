# AI 自主回答格式

2026-10-30最新调整：源码聊天不再执行额外的模型结论复核，保留确定性的引用路径、范围和版本核对。Agent的宽范围检索优先覆盖多个实现文件，限定目录先于截断；回答从当前业务入口组织阶段，分支按本题关注范围展开。只有已结束回答中的rich-content JSON/围栏损坏才沿原模型链最多修正一次语法；合法内容、未知版本/块类型和未完成流均不因此增加改稿。前后端不对正文进行确定性重排，接口与SSE不变。见[源码步骤专项验收](../verification/source-retrieval-steps-20261030.md)。

2026-10-30 起，对话、源码检索、引用核对与回答展示沿用现有基础链路，回答格式由 AI 根据问题和用户要求决定。

## 回答与展示

- 普通 Markdown 和现有 `rich-content` 结构化组件均可使用，不按“流程”“步骤”等词强制转换为卡片，不设置主阅读区字数上限。
- 后端不再自动拆段、去掉长加粗、把参数组合转换成列表，也不额外调用模型压缩或重组流程稿。
- 前端解析并渲染模型选择的格式，保留正文、强调、来源段落和引用标签，不合并来源段落或删除展示文字。字体、间距、代码高亮及组件交互仍由前端控制。
- 用户要求纯 Markdown、原文或保留格式时，模型遵从对应要求。

## 后端内容组织

同日补充生成阶段的阅读组织要求：在展示协议和运行背景之后追加 `ANSWER_ORGANIZATION_GUIDANCE`，由主模型在同一次生成中组织答案。多项参数分行，对比使用共同维度，流程的图或步骤承担主要内容，配文补解释；必要工况及未知单位贴近对应办法和数值。简单回答与用户指定格式优先，不套固定卡片或篇幅。

问题与经验工具提示同步要求避免参数堆叠、图文重复，以及用户未询问的试做顺序或验证计划。经验事实核查发生修订时，要求保留原有列表、表格及合法结构化块，正文与图表的错误数值同步改正。核查通过的正文不因排版重新生成，失败降级规则继续保留。

本次没有增加排版模型调用，也不在后端用正则自动拆段、重新布局或替换 AI 的回答格式。提示要求不能保证每次输出都易读；参数问答与真实调用链实测已有分项呈现，流程样例仍存在重复，见[内容组织验收](../verification/backend-answer-organization-20261030.md)。

## 源码回答组织

后续按用户要求补充源码专项：`agents/prompts/source_answer.py`分别说明功能解释、流程、定位和修改建议的组织方式。由`TaskGuidance`按源码任务、已选代码和实际源码工具使用接入，普通问答沿用原规则。

长工具结果之后追加一次请求级组织提醒，明确它是系统控制消息、不是新的用户问题，并以真实用户的格式与原文要求为准。提醒不写入原消息和聊天历史，同一请求去重，后续普通问答不继承。它让模型在同一次生成中关注本题范围，不增加独立排版调用。

功能解释优先说明作用、条件和返回；流程选择一个完整载体；修改建议默认给一份能定位到文件和方法的最小修改代码。保留源码引用，代码块不混入工具行号；原文请求保留完整代码与缩进，引用置于块外。引用修复沿用相应的组织要求；主模型需区分已读范围、硬件状态及建议与实际实现，源码聊天不再另行调用结论复核模型。

四类真实模型场景、请求隔离和格式保留回归见[源码回答验收](../verification/source-answer-organization-20261030.md)。这些要求仍由模型执行，复杂流程和事实修订后仍可能重复或扩写，不能保证每次输出均达到同样的阅读效果。

## 检索与核对

主模型结合当前问题和对话选择是否调用源码工具。搜索定位与实际读取分开记录，读取的文件、行号、版本形成证据；源码保持只读。

引用覆盖、路径、行号及版本核对继续执行，不再自动执行源码结论语义复核。源码证据相关回答在引用核对结束后发布最终正文，普通聊天继续流式显示。校验失败时保留引用核对提示和原有引用停用机制。

既有 `answer_format_validation` 事件验证模型选择的结构化协议，包括未知类型、版本、非法字段和未闭合围栏。格式校验不触发排版改稿；仅对已结束回答的损坏JSON或围栏沿原模型链最多修正一次语法，仍失败则由前端沿用原文降级展示。供经验事实核查使用的 Markdown 投影不作为排版结果发布。

输出截断后的续写、引用规范化及经验回答的事实错误修正继续保留，它们用于恢复完整回答和核对证据，不用于统一回答风格。

## 数据与范围

本次不修改数据库结构，不清空或迁移正式账号、对话、资料、问题与经验及长期记忆，不修改 `trunk/`。问题与经验和长期记忆沿用现有来源开关，本阶段不重做其检索机制。

旧回答正文和运行档案保持原样；前端统一按保存的内容渲染，因此历史引用标签中的版本和原有独立来源段落可以重新显示。
