# ZX2200 源码模拟耗时分析

更新：2026-10-22。

ARKS 左侧“交接工作台”下方的“动作耗时统计”直接读取所属项目的 ZX2200 源码，按现有 `DryCycle` 模拟分支、固定延时及参数初值计算。打开页面即可看到结果，不需要运行设备、采集或导入文件。`trunk/` 保持只读。

## 使用

进入“动作耗时统计”，选择关联 ZX2200 源码的项目。默认列出动作节点，可切换控制器子动作、换料/放行流程或全部入口，按模块及方法名查找。

“计算依据”显示调用入口、配置初值、分支条件、延时、运动/等待、超时保护、后台任务、文件行号及源码片段。“导出分析”下载带源码指纹与计算口径的 CSV。“重新核对源码”重新读取当前文件，源码变化会使缓存失效。

当前源码识别到 430 个入口：38 个有动作主体的 `ActionNode` 节点、1 个占位节点、384 个控制器公开执行/子动作方法、7 个换料/放行等子流程。这个数字包含父动作和子动作，不表示 430 个独立生产工序，不能把各行相加为整机节拍。节点中保留源码已有的测试节点，名称与类名可见。UI、标定和独立实验目录不作为生产流程分析输入。

以主源码目录中的 `AKRS.ZX2200.csproj` 为边界；解决方案根与应用根可识别到对应的 ZX2200 子目录。原件与 `output/` 副本不会混在一起。多份候选源码无法唯一选择时提示选择单一源码版本所属的项目。

## 已核对的例子

| 动作 | 源码可算部分 | 其他组成 |
| --- | --- | --- |
| S1 焊点定位 | 空跑替代视觉结果，无固定识别延时可直接相加 | 原定位调用与工况判断，不能冒充真实视觉算法耗时 |
| S1 点胶 | 按预点胶与图案调用展开，固定/参数延时单列 | 轨迹、单步/暂停等待和观察循环，不能简单给一个总毫秒数 |
| S2 取片 | 原空跑不执行真实取片，不能套用正常取片 `PickupDelay` | 允许取片等待、XY/Z/安全位运动与暂停等待 |
| S2 上视纠偏 | `AdjustVisionDelay` 显式初值 20 ms；一点停留 20 ms，两点停留 40 ms | P1/P2 移动、后台通知，动作总耗时未定 |
| S2 固晶 | `PlacementDelay` 显式初值 20 ms | 去固晶位及抬起运动，动作总耗时未定 |
| 中转台纠偏 | `IPTPlacementDelay=40`、`IPTPickupDelay=20`，定位停留按一点/两点分别展开 | 放片/取片位置与纠偏运动按原调用关系展示 |

## 计算规则

- 仅解释有限的 C# 数值表达式，不执行源码、设备程序、MSBuild 或硬件 SDK。C# 整数除法、数值转换和 `TimeSpan` 单位分别处理。
- 初值必须来自属性/字段的显式赋值或可跟踪的局部变量/方法参数。参数编辑器的最小/最大范围不是初值；没有可确定值时显示未定。
- 使用原 `DryCycle` 条件。空跑专用的取片、固晶、上视及中转台方法直接列为计算入口；其他节点沿 `DoWork` 调用链展开。正常/离线分支不会直接混加到空跑路径。
- 按正常成功路径计算配置延时。互斥分支合并为上下界；提前返回不会继续累加后续语句；未知分支修改过的局部变量不会继续使用旧常数。
- 简单固定次数的 `for` 按次数计算。未定循环保留每轮延时及条件，不能把轮询 1 ms 当成整个动作只耗时 1 ms。
- 信号/到位等待由实际条件决定。超时是失败保护上限，单独显示，不当作必耗时。暂停及人工处理时间不推造固定数值。
- 运动列出原位置、速度表达式及局部定义。缺少起始位置、有效速度、加减速、硬件配置或精确绑定时保持未定。`|Δ位置|/速度` 仅是恒速下界；同步轴取完成边界，不能逐轴相加。
- 未等待的 `Task.Run` 分支单列，内部延时不加入同步动作。后台执行也不能被当成已经完成。
- 递归、标签跳转、无法绑定的重载及展开边界均保留未解析标记。当前不提供完整 C# 解释执行、跨实例状态推导或整机节拍仿真。
- “可算配置延时”只是模型能确定的组成部分，不包含未经确定的运动、等待与 CPU/回调开销。“无显式延时”不表示实际执行耗时为零。

## 接口与权限

复用当前会话、项目权限及源码工作区边界。独立工作区使用 `independent`；项目路径为 `/api/p/{projectId}/action-timing`。

| 接口 | 用途 |
| --- | --- |
| `GET /source-analysis` | 当前源码指纹、计算口径与入口列表；不需要导入 |
| `GET /source-analysis/{id}` | 一个入口的阶段、参数及源码依据 |
| `GET /source-analysis/export` | CSV 分析结果，带源码指纹及非实测标记 |

源码分析不新增数据库记录，不运行设备，不向模型或外部服务发送源码。原采集协议、历史数据表和工具保留兼容，但主页面已改成源码计算，没有采集/导入操作入口。此前设备依赖是否齐全不影响这次静态分析；无法确定的 SDK 调用会显示未定。
