# ZX2200 源码模拟耗时分析

更新：2026-10-22。

ARKS 左侧“交接工作台”下方的“动作耗时统计”直接读取所属项目的 ZX2200 源码，按现有 `DryCycle` 模拟分支、固定延时及参数初值计算。打开页面即可看到结果，不需要运行设备、采集或导入文件。`trunk/` 保持只读。

## 使用

进入“动作耗时统计”，选择关联 ZX2200 源码的项目。主页面按表格展示，每行一个动作，列为“工位、动作名称、动作耗时、说明、操作”。默认列出主要动作，每页 10 行，支持工位筛选与动作名称搜索。控制器子动作、换料/放行流程及占位节点从表格下方的“查看辅助动作”进入，主表不混入源码方法清单。

“动作耗时”突出能算出的数值；仅能算出停留部分时，下方显示“已知停留，运动与等待耗时未定”，没有可算时间时显示“耗时未定”，不写成零毫秒。停留可能与运动重叠，不用加号暗示直接相加。没有固定停留的空动作也不表示实际执行为零。

“查看详情”先显示耗时与简短说明，展开“查看计算依据”后才显示调用入口、参数初值、分支、公式和源码片段。主页面移除统计卡片、源码指纹、类名、调用点数量和计算公式。“导出表格”导出当前筛选命中的全部动作，字段与主表一致，包含待定组成；不会把未显示的控制器方法一起导出。刷新按钮重新读取当前源码，源码变化会使缓存失效。带完整源码指纹的原始分析导出接口继续保留。

按整个 trunk 的工程引用核对后，当前主表有 47 项主要动作（节点、任务单轮及空跑跳过的上下料任务）。完整目录有 2,257 行，包含控制器、换料、初始化、手动、标定、实验、构造/属性及界面包装；后者从“查看辅助动作”进入。这是分析入口与子动作的目录，不表示 2,257 个独立生产工序，父子行不能相加为整机节拍。

以 `AKRS.ZX2200.csproj` 的 Compile 和 ProjectReference 为依据递归读取已关联目录：当前共 10 个工程、977 个非生成编译文件。378个生成文件只补已有类型的字段声明，不执行布局或事件挂接；声明变化也会使缓存失效。生成文件、未编译文件和未引用工程有独立清单。仅授权主工程子目录时，不自动越界读取兄弟目录；整个 trunk 已关联时可沿引用读取依赖源码。原件与 `output/` 副本不会混在一起。

用户已确认没有硬件配置文件，当前继续展示现有源码可算部分，缺参运动段明确未定，不要求采集或导入。轴配置、请求参数和运行读值的区别见[运动边界核对](../development/action-timing-motion-boundaries.md)。

## 计算规则

- 仅解释有限的 C# 数值表达式，不执行源码、设备程序、MSBuild 或硬件 SDK。C# 整数除法、数值转换和 `TimeSpan` 单位分别处理。
- 初值必须来自属性/字段的显式赋值或可跟踪的局部变量/方法参数。参数编辑器的最小/最大范围不是初值；没有可确定值时显示未定。
- 使用原 `DryCycle` 条件。空跑专用的取片、固晶、上视及中转台方法直接列为计算入口；其他节点沿 `DoWork` 调用链展开。正常/离线分支不会直接混加到空跑路径。
- 按正常成功路径计算配置延时。互斥分支合并为上下界；提前返回不会继续累加后续语句；未知分支修改过的局部变量不会继续使用旧常数。
- 简单固定次数的 `for` 按次数计算。未定循环保留每轮延时及条件，不能把轮询 1 ms 当成整个动作只耗时 1 ms。
- 信号/到位等待由实际条件决定。超时是失败保护上限，单独显示，不当作必耗时。暂停及人工处理时间不推造固定数值。
- 运动列出原位置、速度表达式及局部定义。缺少起始位置、有效速度、加减速、硬件配置或精确绑定时保持未定。`|Δ位置|/速度` 仅是恒速下界；同步轴取完成边界，不能逐轴相加。
- 未等待的 `Task.Run`/`Task.Delay` 分支单列。支持已绑定的零参数源码方法组，以及 `new Task → Start → Wait`；创建任务不会执行正文。await、Wait、WaitAll/WhenAll、WhenAny 按任务发起与完成边界计算，并扣除已并行经过的时间。固定数组逐项绑定，未知成员或改写后不沿用旧时间；动态任务组、复杂返回任务、未绑定委托和取消/超时重载保留未知。模型假设任务可立即调度，不估计实际线程调度开销。
- 服务循环单轮与启动方法分开。`break`、`continue`、异常恢复及提前退出不会继续累加不可达语句；请求/运行状态标志不冻结为启动时的 false。
- 普通标签和goto按源码目标跳转，携带该路径的局部/成员状态；标签后第一条语句参与计算，跳转后的不可达尾部跳过。计数受限的重试给出范围，人工选择或无上限重试保留未知上界；展开预算不作为实际重试次数。离开try时，finally的等待和状态修改先执行，再恢复原跳转、返回或循环出口。
- for按初始化、条件、正文和更新的顺序逐次计算，支持负起点、非单位步长及正文改变计数器/终点；退出时合并正确的变量状态。无副作用的长整数延时循环可精确求和；超过分析预算或次数未定的剩余部分保持未定，不把展开上限当作实际次数。循环内局部变量与重复创建的对象保持各自身份。
- while先计算条件、do先执行正文；break/return不再执行尾部条件。已绑定的方法、属性及Func条件使用本次实际返回值，前后自增与短路表达式按求值时点保存结果。
- foreach的集合表达式只计算一次；已知的一维/矩形数组、List和Enumerable.Range逐项计算，每轮变量各自捕获。矩形数组按各维度计算总元素数，交错数组保留外层与内层；多下标、维度查询、元素修改和引用写入保持对应关系。List枚举期间的版本失效不会显示为正常完成。集合内容、次数或外部写入未定时保留未定，不假定为空或只执行一次。
- 数组接收者、下标、初始化元素及方法实参按源码顺序求值，ref/out可共享已绑定的数组元素；后续赋值不改写前面已经取得的值或引用。超出拷贝/迭代预算的集合元素不填零，恒真且无出口的服务循环不推算成功动作时长。
- 构造中的字段初始化、this/base链和属性访问器可能执行动作，按原调用展开；未调用的委托和nameof、类型转换中的类型名称不计为执行。空条件访问及其参数只在对象非空分支计算。集合RemoveAt不作为运动。
- 已绑定的Action/Func参数按实际调用时点展开，跨方法转发保留创建回调的对象、捕获局部变量与显式参数。回调修改的变量影响后续延时，内部局部变量每次执行独立；已知null跳过。未绑定成员/事件、复杂返回值与未确定异步完成边界保持未定。
- 源码方法及构造链按名称绑定命名参数，补齐可选默认值；实参按源码顺序求值，保留当时的值、对象与ref/out引用位置。包调用使用已核实签名中的真实参数名。无效或无法绑定的源码调用列为未解析，不因Get等名称而显示为完整零耗时；已知停留组成单独展示。
- 包契约只在已关联 DLL 的 SHA-256 与静态核实版本一致时使用，DLL 变化使结果失效。普通轴 AbsoluteMove 的 bool 是额外位置检查开关，false 仍可能阻塞；20 ms 与已启动运动重叠，CamAxis 和不同 AccuracyMode 单独处理。当前驱动的统一物理时间单位尚未证明，运动保留参数与条件公式，不编造数值。
- 递归、未支持的goto case/default、无法绑定的重载及展开边界均保留未解析标记；标签循环能够证明无出口时不推算成功动作耗时。当前不提供完整 C# 解释执行、任意动态引用状态求解或整机节拍仿真。
- “可算配置延时”只是模型能确定的组成部分，不包含未经确定的运动、等待与 CPU/回调开销。“无显式延时”不表示实际执行耗时为零。

## 接口与权限

复用当前会话、项目权限及源码工作区边界。独立工作区使用 `independent`；项目路径为 `/api/p/{projectId}/action-timing`。

| 接口 | 用途 |
| --- | --- |
| `GET /source-analysis` | 当前源码指纹、计算口径与入口列表；不需要导入 |
| `GET /source-analysis/{id}` | 一个入口的阶段、参数及源码依据 |
| `GET /source-analysis/export` | CSV 分析结果，带源码指纹及非实测标记 |
| `GET /source-analysis/coverage` | 同权限下的文件分类、逐方法归属及未覆盖候选数；详细清单不塞进主表 |

源码分析不新增数据库记录，不运行设备，不向模型或外部服务发送源码。原采集协议、历史数据表和工具保留兼容，但主页面已改成源码计算，没有采集/导入操作入口。此前设备依赖是否齐全不影响这次静态分析；无法确定的 SDK 调用会显示未定。

已经计算的报告会按源码和分析器版本保存，本地服务重启后可直接复用。源码、关联包、DLL、工程目录或分析器/解析库版本变化时自动重新计算；缓存损坏或不可写时继续从源码计算，不需要用户导入。首次分析新版本仍需等待完整计算。
