# 动作耗时台账

更新：2026-10-28。

## 当前功能

按用户确认的UI，ARKS“交接工作台”下方的“动作耗时统计”改为用户维护的台账。一行一个动作，显示动作名称、分类、耗时（秒）、备注及编辑/删除操作。标题接入与交接工作台、功能与流程相同的公共顶栏，分类使用横向下划线导航，窄工作区可横向滚动；页面底色、留白、表格及公共控件保持统一。分类栏、名称搜索、耗时状态筛选与分页用于查找数据；切换筛选时保留原表格，避免分类栏闪空。初始不自动生成示例动作、模拟耗时或自定义分类；演示数据须由用户明确要求添加。

- 分类：新增、重命名、删除；删除分类会将动作移到指定分类或“未分类”，保留动作和耗时。目标已有同名动作时整笔取消并提示冲突。
- 动作：添加、编辑、调整分类和删除；耗时允许留空，显示“待填写”，已填0显示为0。同一分类不允许重复名称，不同分类可以同名。
- 排序：点击“耗时（秒）”列头，依次切换从长到短、从短到长、默认顺序。先对全部筛选结果排序再分页；未填写始终排在最后，0参与正常排序，同耗时次序稳定。
- 导入：下载空白Excel/CSV模板，填写“分类、动作名称、耗时（秒或毫秒）、备注”。支持CSV（UTF-8或GB18030）与.xlsx第一个工作表；最多5000行、5MiB。默认识别表头“耗时（秒）/耗时（s）”或“耗时（毫秒）/耗时（ms）”；仅写“耗时”时须选择秒或毫秒。所选单位与表头冲突会提示，不自动猜测。模板按选择的单位下载，自动模式默认秒；预览、保存和普通导出均统一为秒，例如1250毫秒保存为1.25秒。切换文件、单位或重复策略后须重新预览。先校验、预览，再确认写入；有错误时不能确认，文件内同分类同名行需合并。空分类归入“未分类”，新分类自动创建。已有动作可选择跳过或更新；更新时空耗时保留原值，备注以文件为准。需要清空已有耗时时使用编辑动作。
- 导出：Excel或CSV，选择全部动作或当前筛选结果，包含命中的所有分页，并沿用当前排序。空台账也可导出表头；导出文件可修改后重新导入。Excel公式需先转为数值，系统不执行公式。
- 耗时项目：按设备或业务项目独立维护，默认名称为“智芯2200”。下拉框旁的“管理耗时项目”支持添加和重命名。左侧项目只管理聊天；创建、切换、重命名、归档或删除聊天项目均不影响耗时项目及其台账。
- 数据隔离：耗时项目及分类、动作按账号权限保存，管理员保留管理访问，重启后保留。编辑版本和导入预览版本过期时会提示刷新，避免覆盖其他修改。已有台账升级时保留全部分类、动作、耗时及备注，仅增加独立耗时项目档案，不复制聊天项目或对话。

2026-10-28 已移除停用的源码耗时模拟器、专用契约、测试和 `source-analysis` 接口；这些地址在登录后返回404。当前台账不依赖源码分析器，不运行设备或容器。聊天中的源码搜索、阅读和分析属于独立模块，继续保留。

数据库模型、历史迁移、已有台账和旧采集批次及其兼容接口保留；已保存的历史报告不读取、不删除，也不自动导入台账。`trunk/`保持只读。旧方案和验收仅作[历史记录](../archive/action-timing-source-simulation.md)，本次范围与结果见[移除验收](../verification/retire-source-timing-20261028.md)。

## 当前接口与验证

当前页面使用 `/api/action-timing/projects` 管理独立耗时项目，使用 `/api/action-timing/ledger` 及其分类、动作、导入预览、确认和导出子接口维护台账。选择项目使用 `timing_project` 参数，不与左侧聊天项目同步。接口继续受会话、账号权限和CSRF校验保护。

相关回归覆盖空台账、分类/动作增删改、零值与待填写、筛选/排序/分页、Excel/CSV与毫秒换算、导入冲突和并发、账号/项目隔离、迁移及重启后保存；另外检查已移除地址返回404且不改变台账和历史报告。实际执行结果见本次移除验收。
