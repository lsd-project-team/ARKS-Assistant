# 账号与交接工作台访问控制

2026-10-15。管理员与普通用户使用各自的工作区，保留原登录页，个人账号入口统一放在工作页面右上角。管理员工作区提供七项管理功能，普通用户保留 AI 问答与日常交接流程。

## 使用

首次升级启动会初始化 `admin`（管理员）与 `user`（普通用户），分别生成随机密码，保存到服务端本机 `data/auth.initial-accounts.json`。密码使用 Argon2id 哈希入库；初始化文件不进入 Git、日志、HTTP 响应或导出备份。由本机管理员读取并分发相应账号的密码。

访问 `http://127.0.0.1:8765/`，未登录时进入登录页。已经登录后，访问 `/#login` 可以切换账号。账号角色由数据库决定，浏览器输入的姓名、职责或请求头不会授予管理员权限。

本机账号维护命令在 `backend` 目录运行，密码通过交互式隐藏输入提供：

```powershell
uv run python ../scripts/maintenance/manage_accounts.py list
uv run python ../scripts/maintenance/manage_accounts.py add engineer01 --role user --name 工程师
uv run python ../scripts/maintenance/manage_accounts.py password user
uv run python ../scripts/maintenance/manage_accounts.py role engineer01 --role admin
uv run python ../scripts/maintenance/manage_accounts.py disable engineer01
```

支持 `enable` 重新启用。密码修改、角色修改和禁用会撤销对应会话；不允许禁用或降级最后一个有效管理员。管理员也可在“用户管理”新增、编辑、启停账号和撤销会话。

## 右上角账号菜单

账号和身份显示在公共顶栏，流程图谱、功能说明、对话、项目首页与交接工作台使用同一个入口。打开源码分栏时，入口仍位于整个工作区最右侧。窄屏保留账号和展开按钮，完整账号和身份在菜单中显示。按确认后的调整，入口、菜单和个人信息弹窗均不显示头像。左侧栏不增加个人信息区域。

- 个人信息：读取当前真实会话，显示账号、显示名称和身份；不允许自行修改角色。
- 修改密码：填写当前密码与两次新密码，新密码支持 6–256 个字符。服务端从会话确定账号，校验当前密码和两次新密码，使用 Argon2id 更新哈希，并撤销该账号所有窗口的会话。成功后返回登录页并提示重新登录，其他账号的会话不受影响。
- 退出登录：通过原有 `POST /api/auth/logout` 撤销服务端会话，再清除前端查询缓存和 CSRF，其他窗口通过广播重新核对登录状态。

自助修改密码使用受会话和 CSRF 保护的 `POST /api/auth/password`，新密码不会写入初始账号文件。该文件仅提供初始化时的凭据，用户自助改密后应使用自己设置的新密码。

## 可见范围

| 内容 | 管理员 | 普通用户 |
| --- | --- | --- |
| 资料、任务与进度、交接包 | 保留现有功能 | 保留现有功能 |
| 复核与追溯页面和导航入口 | 可见 | 隐藏，直接访问网址返回概览 |
| 概况中的复核与追溯卡片 | 可见 | 隐藏，也不请求操作日志 |
| 修改与确认历史、审核意见与审核身份 | 可见 | 不显示，历史接口返回 403 |

| 全量备份及恢复校验 | 保留 | 接口返回 403，相关设置控件只读 |

系统配置和全量备份受限是为了防止通过服务器命令、任意源码目录或数据库备份读取初始密码和复核记录。现有设置标签仍保留；外观、知识来源和长期记忆按原有方式使用。普通用户的项目和对话现已按账号隔离，公司交接资料与调试问题继续共享。

2026-10-15 更新：个人偏好记忆按登录账号隔离，包括读写、冲突检查、修订恢复与运行详情中的个人记忆正文。项目、对话和项目记忆也按账号范围隔离；后台排队按实际提交人的账号读取记忆。旧公共用户记忆保留原件，不自动分配归属。见 [对话知识优化](chat-knowledge-improvements.md)及[项目与对话隔离](account-workspace-isolation.md)。

公司源码统一默认可用：普通用户登录时自动获得各自的默认项目，自动关联同一份公司源码和仓库。新建项目及独立对话也能直接使用公司源码；私人问答、项目指令、项目资料和记忆不随源码共享。普通用户无需逐人请求绑定，也不能将目录切换为任意服务器路径。

## 会话与边界

- 业务 API 需要有效服务端会话，未登录返回 401；健康接口保留启动器所需行为。
- Cookie 为 HttpOnly、SameSite=Strict，HTTPS 时为 Secure。会话绝对有效期为 12 小时；重启或恢复备份后旧会话失效。
- 会话凭证仅以 SHA-256 摘要存储；角色和启用状态每次请求从数据库读取。写入使用独立 CSRF 令牌。
- 登录失败提示不区分不存在账号、错误密码和禁用账号；同一来源 5 分钟内 10 次失败后限流。
- 前端只根据已核验的服务端身份显示内容；账号切换先清理全部项目查询缓存，跨窗口广播重新核验，定期检查会话。
- 保持现有本机监听和允许来源，未调整内网部署或开放注册。

密码和会话设计参考 [OWASP 密码存储](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)、[会话管理](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html)和 [CSRF 防护](https://cheatsheetseries.owasp.org/cheatsheets/Cross-Site_Request_Forgery_Prevention_Cheat_Sheet.html)。

## 验收

### 管理员工作区与统计口径

- 主导航为管理概览、用户管理、AI 问答记录、交接管理、复核与追溯、系统配置、数据维护七项；无独立项目管理菜单。源码关联、仓库、指令、项目资料、知识来源和长期记忆并入系统配置。
- 管理员界面不挂载聊天输入、会话列表、源码聊天分栏或“在对话中讨论”入口。AI 问答记录只读，普通用户的 AI 问答保留。
- 问答按用户、项目、日期、正文关键词和状态检索，详情分页展示完整原始消息、代码选区、所有回答版本、模型、耗时、错误与供应商实报用量。源码引用按保存的目录身份打开并核对版本。
- 每次提问保存服务端账号快照；排队、后台出队和分支复制保留身份，修改问题采用本次提交者身份。历史没有身份或用量的记录标记未记录，不补猜。
- 首页统计普通用户的实际使用。访问量按每次加载用户端页面登记，同页切换不重复登记；活跃用户按有效活动或成功业务提交去重。
- 前台、有焦点且 60 秒内有操作才累计时长；后台、失焦、空闲和休眠不补时间。心跳使用递增序号，服务端限额且对同一用户多窗口重叠时长去重。
- 任务次数按成功业务保存计数，AI 问答成功落库后按问题计一次；失败、取消、重生成、内部调用和重复提交标识不重复计数，恢复运行成功仍按原问题去重。
- 支持最近 7 天、最近 30 天、自开始采集。前四项按时间范围计算；数据量始终取当前项目、资料、长期记忆、问答消息和交接记录存量，含归档，排除已移除项目/资料、回收站消息、修订、日志和 AI 中间记录。页面显示具体构成。
- 采集开始时间持久化，重启保留；不依据旧消息补造历史访问、时长或成功提交事件。每日趋势按北京时间汇总。
- 用户管理变更与会话撤销同事务执行，保护最后一个有效管理员。管理日志不记录密码、密钥或配置正文。未保存的系统配置切页时提示保留或放弃。
- 数据维护保留存储统计、备份导出、备份校验与停服恢复步骤。固定历史版本地址、原始问答与既有业务数据保留。
