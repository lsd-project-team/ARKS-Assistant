# 问题与经验

交接工作台原“调试问题”更名为“问题与经验”，集中保存问题处理、优化与经验、工作进展、资料归档。原有 `issues` 路由、`debug_issue` 记录类型、固定版本引用和 `/记录问题` 命令保持兼容。

问题处理使用“未解决 / 已解决”，标记已解决仍须填写处理办法。其他类型显示“已记录”，不表示问题解决、工作验收或验证通过，也不自动生成未解决待办。

事项日期、原记录人、原记录时间分别保存，不从记录时间推断事项日期或年份。系统录入人独立维护，不能用原记录人的名字替代实际录入账号。历史记录没有新字段时仍按问题处理展示。

列表支持全文、类型和状态筛选；详情展示实际填写的字段与录入原文。后续问答检索携带记录类型及原始日期、作者，区分历史事实、已记录进展和实际解决反馈。

业务记录、备份和批量导入原文仅保存于本地数据目录，不提交到 GitHub。
