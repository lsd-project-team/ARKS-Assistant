# 全站字号层级

公共字号定义在 `frontend/src/shared/styles/typography.css`，各模块沿用自身选择器和布局，引用同一组变量。

| 信息角色                   | 字号 | 变量                                            |
| -------------------------- | ---- | ----------------------------------------------- |
| 正文、用户问题、聊天输入   | 16px | `--font-size-body`                              |
| 按钮、输入框、菜单、文件名 | 14px | `--font-size-control`                           |
| 说明、时间、状态、增删统计 | 13px | `--font-size-meta`                              |
| 代码、日志                 | 14px | `--font-size-code`                              |
| 数据表格正文               | 15px | `--font-size-table`                             |
| 页面标题                   | 22px | `--font-size-page-title`                        |
| 区块标题                   | 18px | `--font-size-section-title`                     |
| 卡片小标题、工作区顶栏     | 16px | `--font-size-subtitle`、`--font-size-bar-title` |
| 弹窗标题                   | 20px | `--font-size-dialog-title`                      |

覆盖聊天输入与状态、变更摘要和差异区、源码文件栏、项目与账号菜单、设置及公共弹窗、登录、功能资料、交接工作台、动作耗时表和管理页面。普通表单及下拉选项使用 40px 控件高度，图标按钮保留自身尺寸；窄聊天栏的修改摘要隐藏装饰图标，标题与操作按可用宽度换行。

AI 回复使用独立阅读方案：宽窄栏正文均为 16px、26px 行高，Windows 中文优先使用微软雅黑 UI；代码块保持 14px、表格保持 15px。左侧导航继续主文字 16px、辅助信息 13px。欢迎页及登录品牌大标题、统计大数字、画布中的节点与图表坐标保留原比例，不作为普通页面正文处理；流程阅读器的页面标题仍使用统一的 22px。

## 源码阅读设置

源码阅读器新默认字号为 14px，行高继续按字号乘以用户设置的倍数计算。恢复未带 `sourceTypographyVersion` 的旧状态时，仅将旧默认 12px 升为 14px，同时记录版本 1；其他自定义字号保留。升级后手动选择的 12px 也会保留。草稿、账号隔离、文件历史和阅读位置继续使用原持久化机制。

## 维护方式

新增普通正文使用 `var(--font-size-body)`，控件使用 `var(--font-size-control)`，辅助说明使用 `var(--font-size-meta)`，避免再给同一角色新增零散的 10～15px 固定值。字号变量只负责信息层级；换行、虚拟列表行高和控件空间仍由各自组件负责。更改变量后需检查按需加载的业务样式、分屏窄栏和持久化阅读偏好，不能只验证首屏聊天。
