# 旧版代码副本流程（已移除）

更新日期：2026-11-12。

原“每个对话复制一份工程 + 合并预览 + 候选验证 + 管理员写回”的代码修改流程已经移除，包括：

- 副本创建、恢复、备份与 `data/scratch/cw` 目录管理；
- 合并预览、冲突处理、候选验证、写回与回退；
- 需求断言宿主、桌面流程、固定 C# 验证；
- 管理员“编译与仿真环境”页和 `/api/settings/code-work`、`/threads/{id}/code-work/*` 接口；
- 前端差异面板、合并面板、验证报告、修改摘要。

替代方案是原地编码 Agent：项目目录即工作区，通用文件工具、Git 快照回滚、项目内命令执行与审批。见[原地编码 Agent 方案](in-place-coding-agent.md)和[第一阶段验收](../verification/coding-workspace-20261112.md)。

旧副本目录和旧合并记录不再自动清理，如需释放空间可手动删除 `data/scratch/cw`；对话、消息、记忆和知识索引不受影响。
