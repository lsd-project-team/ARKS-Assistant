## 访问范围

- 新项目、新对话由服务端记录当前登录账号，客户端不能指定或改写归属。对话分支继承原对话归属。
- 普通用户的项目列表、最近、归档、回收站、搜索、计数、置顶和排序只包含本人数据。没有项目时可以直接发起独立对话。
- 项目详情、修改、移除、移动对话、导出、项目资料及其历史、项目记忆和源码历史引用均校验归属。对话消息、队列、上下文、运行详情、轨迹、SSE、停止、恢复和重生成也使用同一边界。
- 其他账号的资源返回 404，不能通过复制链接、缓存过的项目服务、旧版 `/api/threads` 等无前缀接口绕过。管理员保留全量管理和问答查看能力。
- 项目内资料、结论、指令和项目记忆只服务于所属账号的项目及其中的对话。独立对话的记忆、默认知识来源也按账号保存。
- 全局交接资料、调试问题及用户主动提交给交接工作台的正文继续共享。分享后的记录不自动赋予其他人读取原私人对话、原项目或实时源码目录的权限。
- 公司统一配置的源码为所有账号默认只读可用，默认项目与新建的普通用户项目自动关联该源码。独立对话也使用公司源码；用户主动归档或移除默认项目后，不在每次登录时重复创建。管理员配置的其他私人源码目录仍按项目归属校验，普通用户不能关联任意服务器目录。

## 浏览器状态

工作区状态保存为 `trunk-workspace:account:<账号ID>`，项目选择、对话选择、未发送草稿、选区、阅读位置和项目展开状态分别恢复。退出时清空内存及查询缓存，不删除已保存的本人草稿。

旧公共 `trunk-workspace` 原件保留，只把服务端确认属于当前账号的项目及对话状态复制到该账号。未知归属的草稿不会自动显示给新登录账号。旧账号请求的晚到响应会被忽略；浏览器请求携带预期账号，服务端拒绝 Cookie 已切换但页面仍使用旧身份的请求。
