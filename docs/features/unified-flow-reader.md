# 统一图谱阅读器

“功能与流程”的 121 个公开图谱入口共用图文同屏布局，包括 8 条生产主流程、旧专题图、46 张模块图解，以及坐标、视觉、标定等内嵌阅读页。业务专题仍按现有分类组织。

## 阅读方式

- 页头统一显示当前位置、标题、摘要和目录入口。
- “图谱阅读”默认左图右文，画布随窗口高度调整；内容区不足 880px 时，说明自动移到图下。
- 工具栏统一提供节点查找、适应画布、缩小、原始大小、放大、全屏、收起说明及 SVG 导出。表格、公式没有图形相机，相应操作保持不可用。
- 原图初次按画布完整展示。密集图可放大、拖动或全屏，点击节点和查找结果后，说明区展示该对象的信息；点击关系可定位另一个节点。
- “详细说明”延迟加载，返回图谱时保留原画布、节点和缩放。模块文档继续支持章节搜索、章节链接、前后章导航及跨文档链接。

## 内容约定

原有流程图、架构图、时序图、状态图及坐标关系图保留交付的 SVG、节点和连线，不改成统一的串行步骤。导出包含完整原图，而不是当前缩放窗口。

原图有明确节点说明时显示名称、附注、所属环节及关系；生产主流程还显示已有节点说明与交接条件。不从名称猜测执行条件，也不声称未经映射的节点对应某个文档章节。详细文档入口保留完整业务解释。

坐标、标定等专题继续使用原有关系图、公式、数值例子及保存对照表。已有逐条说明没有专用图形时，按其已定义的阅读顺序展示环节图；原说明标为并列分支的内容不添加执行箭头。说明范围和全部返回分支保留在详细说明中。

## 实现与维护

公共组件位于 `frontend/src/features/knowledge/reader/`：

| 文件                   | 职责                                                |
| ---------------------- | --------------------------------------------------- |
| `ReaderPageHeader.tsx` | 页头与目录导航                                      |
| `ReaderTabs.tsx`       | 图谱和文档切换，保留挂载状态                        |
| `ReaderFrame.tsx`      | 工具栏、节点搜索、说明区及全屏                      |
| `DiagramViewport.tsx`  | 原图载入、相机、拖动、节点事件及完整 SVG 导出       |
| `diagramDocument.ts`   | 提取原 SVG、保留配色预设，去除脚本、外链和嵌入 HTML |
| `flowDocument.ts`      | 将已有说明环节绘制为可选择的阅读图                  |
| `CatalogReader.tsx`    | 旧目录图的业务说明及模块协作适配                    |

阅读副本使用禁止脚本的同源 iframe，原交付查看器的工具栏、浮层和脚本不再嵌套。原 HTML、Markdown 和资源指纹不变。坐标图有窄版交付时，按实际画布宽度切换。正文内的补充插图继续使用原静态阅读组件。

新增图谱入口应经过目录枚举测试，并由公共阅读器展示。已有事实、配置和风险说明的复核状态不因 UI 统一而改变；本次不调整源码分析、AI 检索、后端或正式业务数据。
