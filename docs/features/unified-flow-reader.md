# 统一图谱阅读器

2026-11-11，业务专题及相关入口移除。“功能与流程”直接进入图谱目录，页头统一返回“全部图谱”。原专题中的补充流程并入对应主图，通过阅读环节按钮切换，任一时刻只显示一个画布；用途、运行条件和异常说明放在图下。G0、标定等图谱的公式和表格沿用，旧专题链接自动转入对应图谱。内容归属见[图谱归并清单](flow-graph-catalog.md)。

2026-11-04，功能与流程的 121 个公开图谱入口改为默认整宽全图阅读，移除独立的详细说明页签、正文与入口。

## 阅读与缩放

- 默认关闭节点信息，画布使用完整内容宽度；节点信息按需展开在图下，不压缩图的宽度。
- 默认适配完整图形，四周留出边距。长竖图按比例随页面延展，避免固定高度把节点压成小字。
- 选中节点只高亮，完整图可见时不移动相机。放大后仅为越出视口的节点补足平移。
- 缩放与拖动受图形边界限制；Ctrl＋滚轮围绕鼠标位置缩放。“适应画布”和点击缩放比例均恢复全图。
- “清晰阅读”按节点字号放大以阅读文字；节点名称也显示在图下。狭窄窗口内的密集全图可用此入口查看细节，再一键恢复全图。
- 节点标题仅在原有边框及其他文字留出的空间足够时增大字号，避免标题、副标题互相覆盖。
- 节点查找、全屏及完整 SVG 导出继续可用。表格、公式没有图形相机，对应缩放操作不可用。

## 内容与资源

原有流程、架构、时序、状态及坐标图继续保留各自的节点、关系和布局。坐标、标定等专题的公式、数值例子及对照表保留。已有说明环节图只为明确有顺序的流程绘制执行箭头。

独立文档阅读组件及相关入口已移除，旧的 `?section=` 链接直接显示图谱，不再加载正文。原 Markdown 和交付 HTML 作为源资料留在 `resources/knowledge/flows/manuals/`，不删除用户原始文件，也不新增 AI 检索入口。

## 实现

公共组件位于 `frontend/src/features/knowledge/reader/`。

| 文件                   | 职责                                       |
| ---------------------- | ------------------------------------------ |
| `ReaderPageHeader.tsx` | 页头与目录导航                             |
| `ReaderFrame.tsx`      | 整宽画布、工具栏、查找及按需节点信息       |
| `DiagramViewport.tsx`  | SVG 载入、事件、字体完成后的测量及完整导出 |
| `diagramCamera.ts`     | 全图适配、缩放锚点、平移边界及画布高度     |
| `diagramText.ts`       | 在节点原有空间内提高标题字号               |
| `diagramDocument.ts`   | 提取原 SVG，保留配色并剔除脚本、事件和外链 |
| `flowDocument.ts`      | 将已有说明环节绘制为阅读图                 |
| `CatalogReader.tsx`    | 旧图谱与节点信息适配                       |

阅读副本使用禁止脚本的同源 iframe，不嵌套原查看器的工具栏与脚本。相机始终按当前画布尺寸计算，字体就绪后在原始 viewBox 中测量，防止百分比装饰层随相机重复扩大。坐标图有窄版时继续按实际画布宽度切换。
