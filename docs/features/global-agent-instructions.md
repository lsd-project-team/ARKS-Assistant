# 账号全局 agent.md

每个账号可以在“设置 → 全局 agent.md”维护一份长期用户指令，适用于自己的所有项目和独立对话。普通用户和管理员均可编辑自己的文件；项目设置不增加指令入口，也不自动读取业务源码目录中的 `agent.md` 或 `AGENTS.md`。

例如可以写：

```markdown
# 回答习惯
默认用中文，先给结论，再说明必要依据。
分析源码时标明适用条件；没有验证的内容明确说明。
```

保存后，下一次启动的问答使用新内容；已启动的问答使用启动时的固定版本。无需新建聊天。留空保存后不再带入自定义指令。编辑内容最多 32 KiB，按 UTF-8 字节计算；其他窗口已保存新版本时拒绝覆盖，读取最新内容后再编辑。

## 与 Codex 设计的关系

参考 [Codex AGENTS.md 配置](https://learn.chatgpt.com/docs/agent-configuration/agents-md)：用户维护的全局文件在执行开始前读取，作为用户指令放在当前任务前面，并有文件大小限制。Codex 还支持项目、子目录和 override 文件；本应用按用户要求只保留账号全局一层，文件名统一为 `agent.md`，不实现项目层级。

全局文件表达默认约定，当前问题的明确要求优先，不能改变系统权限、工具能力与事实核查要求。文件通过用户消息进入模型上下文，不作为系统提示词，也不依赖“长期记忆”来源开关。文件由用户主动编辑，后台记忆任务不改写它，聊天也没有自动修改该文件的工具。

## 保存与执行

- 文件位于 `data/instructions/<账号ID的SHA-256>/agent.md`；路径由服务端登录身份决定。
- 全局接口为 `GET/PUT /api/agent-instructions`，写入只接受 `content` 和版本哈希 `version`，不接受目标账号或项目。
- 每次问答固定一份快照，执行过程中重复调用主模型时使用同一份内容。摘要后再次带入，避免长聊天压缩时丢失。
- 不写入原始聊天和 Agent 检查点，不作为后台记忆提取的用户事实。上下文预算单列“全局指令”；超过模型总预算时阻止请求并提示精简。
- 运行档案记录脱敏后的版本与内容；只允许发起账号查看。其他账号查看共享聊天时，上下文、执行记录和事件接口隐藏私人指令。供应商请求沿用既有敏感字段脱敏。

备份包含个人指令文件，恢复与数据库、记忆、原文档案共同执行；恢复旧版且不含指令目录的备份时，保留目标机器现有指令。管理员导出的完整备份属于本机管理资料，包含各账号的个人文件，按现有数据维护权限管理。
