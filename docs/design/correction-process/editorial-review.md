# 纠偏过程分册编校记录

第1.0版，2026年10月20日。当前稿完成源码静态复核、编校、图文核对与全页校样，可供两类读者阅读及技术评审。

## 内容与设计说明

- 第3章分别说明逐点采集、独立选轴、锚点与角度、绕锚点更新、严格超限条件，以及S1/S2距离异常的不同路径。
- 四点角度计算保留实际P4读取第3点UseAngle的条件；两点定角保留Atan应用于角差的行为；三点圆退化分支按源码说明。
- 第4章区分单/双点及快速/普通上视，正常几何PR次数为1/2/2/4；镜像的实际旋转表达式与保存的角度表达式分别说明。
- 新追踪温漂包装、内部计算与取值链：包装没有使用内部bool且最终返回true；内部识别失败仍可能请求停机，取值超限另抛异常。不把调用处Abort判断写成底层成功保证。
- 第5章分别说明中转台的重取几何、拍照位与统计字段；正常RePick标签在Pick之后，视觉Ignore中的Repick标签在PickAction之前，分别画图。
- 第6章按实参顺序保存实时补偿接口映射，并说明轴转换后的追加位置；只解释纠偏输出的必要使用。
- 第7章保留结果先写而后续失败的情况；人工OK会重新运行匹配PR，确认结果返回后，上视/中转台直接使用并跳过正常的选轴后处理。

正文先介绍对象和问题，再解释数据、步骤与约束；接口与源码定位用于深入核查。编写说明提供研发评审和设备调试两种阅读路径，末章用可回查的问题核对理解。没有把源码文件列表当成设计正文。

## 图文与版面

- 13幅图、6张表；图注说明读法、前提、参考系或分支范围。概念图使用内置生图工具，数值、时序、字段和异常图按实际逻辑精确绘制，保存可维护图源。
- 标题、章节编号、目录统一微软雅黑；正文宋体。移除会覆盖显式字体的主题属性，Word更新字段后再次统一目录字体；核查实际PDF字体资源。
- 正文连续排版，附录分组。图、图注和解释相随；关键小表避免单行拖到次页；长字段与接口名称明确换行；不靠缩小正文来凑页数。
- Word保留原生目录、书签、公式和引用；图表页码使用可更新字段。PDF内所有字体已嵌入，所有插图保持不低于300dpi。
