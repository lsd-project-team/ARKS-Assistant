# 纠偏过程设计文档要求对照

第1.0版，2026年10月20日。以下是可审查的内容与检查证据，不将图数、页数或程序断言单独作为可读性结论。

| 要求 | 对应内容与证据 |
|---|---|
| 独立设计分册 | 正文按设计对象、职责、数据、步骤、接口与约束组织；两册分别交付 |
| 兼顾研发评审与设备调试 | 编写说明提供两种阅读路径，正文先解释含义，再给计算与契约；末章问题能回查章节及图示 |
| 对象与输入输出设计 | 第1、2章区分产品定位、上视与中转台，列明配置、结果归属、参考系与单位 |
| 产品定位设计 | 第3章覆盖入口、逐点采集、选轴与角度、锚点更新、距离检查及S1/S2异常差异 |
| 上视纠偏设计 | 第4章覆盖四种模式采集时序、快速与普通计算、镜像、温漂与返回边界 |
| 中转台纠偏设计 | 第5章覆盖放片、识别、中心与取片计算、重新取片、统计字段和两个不同重试标签 |
| 输出使用及接口 | 第6、8章说明保存偏移如何使用、实时补偿实际参数次序与追加位置；接口表明确副作用与前提 |
| 异常及算例 | 第7章及附录C保留部分写入、人工OK、Retry与消息重置；9个独立说明算例全部复算通过 |
| 分析依据可追溯 | 源码附录、source-guide.md、source-baseline.json与claim-map.json定位主要结论；30个源码文件哈希和锚点核对通过；阅读范围另有记录 |
| 图文并茂 | 13幅图对应具体设计问题，均有编号、图注、前提或读法；生成式概念插图与精确工程图共同使用；图中文字、方向、数量与正文核对 |
| PDF整齐且可阅读 | 24页逐页查看；标题、正文、表格与页码一致，修改页重查；目录和图表页码、字体嵌入、边界和插图分辨率检查通过 |
| 可维护交付 | PDF、可编辑Word、Markdown、SVG/PNG、源码与算例索引、插图来源及编校记录齐备 |

本轮编制和检查工作已完成，交付范围为可阅读、打印和技术评审的设计文档。没有取得独立读者试读或用户验收反馈，也没有执行设备验证；这些事实不以自动检查通过替代。
