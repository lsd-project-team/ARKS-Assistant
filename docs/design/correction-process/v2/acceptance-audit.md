# 纠偏过程设计文档要求对照

第2.0版，2026年10月20日。

| 要求 | 本轮依据 |
|---|---|
| 独立设计文档 | 保留职责、数据、坐标、主要流程、接口、约束及异常说明；两册分别组织 |
| 源码深入且可追溯 | 主要入口、计算、写回和返回边界可从引用追到source-guide及claim-map；当前源码哈希与锚点核对通过 |
| 给两类读者阅读 | 先说明物理对象与设计含义，再给变量和实现条件；保留开发查阅所需契约和设备理解所需动作阶段 |
| 图文对应且直观 | 图5-1是否始终只有一枚芯片、识别相机是否朝下、对位移动的是吸嘴、重取后台面是否空；图5-2是否区分相对向量、绝对G0坐标和相对Q的局部增量，并保持各窗X/Y等比例。 |
| PDF布局可用 | 24页最终校样均有检查依据；关键小表同页、引用无独行、字体嵌入及图像分辨率检查通过 |
| 计算明确 | 变量、单位、参考系、说明输入及独立复算保留；详见arithmetic-verification.json |
| 可继续维护 | PDF、Word、Markdown、所用SVG/PNG、来源和校样记录齐备 |

第2、3、4、5章先解释物理含义，再定义变量、条件和实现边界。3.3节用少量加粗标识算法分支。图5-1改为生图连续场景，图5-2改为精确向量及偏心局部放大图。保留四点角度、两点Atan、S1/S2距离检查、人工OK、温漂返回和两个重试标签的实际行为。

这些证据支持本轮交付用于阅读、打印和技术评审；没有取得独立读者试读、用户验收或实机验证结果，未以数量指标替代这些事实。
