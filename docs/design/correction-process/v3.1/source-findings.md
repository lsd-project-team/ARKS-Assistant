# 纠偏过程本轮源码核查发现

范围严格限定为trunk/AKRS.ZX2200。

- Nine缓存省略的是初次候选确认，MoveDieToPickCenter仍会再次PR；bondSpinAngle写在后次PR之前，后次void失败不直接把本轮搜索改为false。
- WaferMap当前仅支持开启定位的标准单点；双点、MultipleSearch及关闭定位的分支抛异常，不再并列为已支持模式。
- 候选存在、允许取料及取后更新分开；预取推进、跳板/跳片、RefreshMap及供料信号次序补齐。
- 八个产品定位入口逐项说明None、工艺范围、定位标记、完成与EntityState条件；1024组纯条件组合与源码语法表达式比对通过。
- 普通生产镜像与非镜像补充准备、实际旋转、保存角和后续目标的完整追踪；快速模式不额外加入普通镜像180度项。
- 手动上视准备T独立，普通双点未检查IsMirror；快速单点返回的四维T及关灯路径也与公共尾段不同。
- 手动贴片SelfPosToG0(q)+o与生产分开解释；0角度例分别得到(100.2,199.6)与(100.1,199.8)，不以统一公式掩盖实现差异。
- 漂移、焊后、单点、TU网格与实时点组的更新、失败保留及读取寿命补齐；TU.Refresh不统一清空单例/静态缓存。
- 既有中转台目标提前写入、绝对/插补返回差异、两侧距离异常和人工OK后处理差异均保留。

54条两册关键结论分别由本册claim-map.json定位。全目录语法扫描不等于逐文件业务通读；入口清单65个文件逐项归类，关键方法已读范围另见source-analysis.json。未执行C#或设备。
