# 纠偏过程源码核查发现

源码范围严格限定为trunk/AKRS.ZX2200。

- 补齐供料四种搜索、多次定位、静态华夫盒取片公式与漂移；人工OK跳过自动阈值判断，返回true不等于自动达标。
- 八个层级定位动作均检查编译和注册，区分S1/S2离线、Divide、EntityState及完成条件；相对固晶定位在对应Pick前。
- IPTVisionPos、IPTPickPos在运动前写入；绝对运动部分包装未接收底层返回，与插补传播路径不同。
- 手动PlacementTest使用独立上视实现，启用纠偏时不支持中转台；示教、实验和标定输入另作归属。
- 补偿次序、焊后空筛选与Z字段、TU网格及实时插值异常/最终置零分别说明。
- 删除目录外坐标内部阈值断言，坐标公式明确作为几何说明模型；保留目录内调用契约。

关键结论、方法和复核区间见claim-map.json及source-analysis.json；已发现入口逐项归属见entry-coverage.md。文本发现与关键方法语义核查分别记录，不以文件数量声称全项目理解或形式化可达性证明。
