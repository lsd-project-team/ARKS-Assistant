# 本轮源码核查发现

业务源码保持只读，检索、读取、调用追踪均限制在trunk/AKRS.ZX2200。

当前索引1158个C#文件；103个候选文件逐项归属。索引不等于通读；实际已读区段和结论见source-analysis.json、claim-map.json。

旧版56个依据文件哈希及既有结论锚点全部一致；本轮保留原生产正文，重点新读设备轴、角度示教和区域表生成维护。

## 入口证据边界

FrmBondCompensate可由主界面ShowForm<T>打开。FrmAutoCompensate编译项、Designer事件与内部实现存在；全目录语法调用、构造及泛型搜索未发现其他代码直接打开它。不能据此断言不可达，也不能声称已接入每轮生产。
CompensationPredictor在标定界面存在调用分支，但初始化代码被注释，未作为生产AI补偿写入。GooGolCompensate／EtelCompensate空类不代表实际驱动补偿缺失，真正调用包装位于Infrastructure/Utils。

## 验证边界

本轮使用原生Word导出并恢复原始图片流。独立纯CompensateCalculator C#类可编译复算；未加载设备程序集、运行设备或执行整套C#业务。其余数值和条件按独立模型检查。驱动SDK及外部坐标库内部不展开。
