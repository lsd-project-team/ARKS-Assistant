# Transport Unit设计分册

第4版，2026年10月20日。兼顾研发评审与设备调试人员。本轮统一配图视觉规范和标题、编号、目录字体，修正Word更新字段时的字体回退。

- `TransportUnit设计文档.pdf`：阅读与打印稿，带原生目录跳转和书签。
- `TransportUnit设计文档.docx`：可编辑稿，保留标题层级、目录、公式及引用。
- `TransportUnit设计文档.md`、`figures/`：正文与插图维护源；精确工程图提供SVG和PNG。
- `illustration-provenance.json`：两幅概念图的内置生图提示词、精修记录和图像路径。
- `source-baseline.json`、`claim-map.json`：源码基线及技术结论定位。
- `editorial-spec.json`、`editorial-review.md`、`verification.json`：版式规则、编校记录与验证范围。
- `image-resolution.json`、`acceptance-audit.md`：图像清晰度与原要求对照。

正文按产品地址、对象模型、坐标、构建、生产生命周期、接口、边界和贯穿实例展开。源码保持只读，说明算例不是设备实测。纠偏正式分册按约定在TU确认后编写。
