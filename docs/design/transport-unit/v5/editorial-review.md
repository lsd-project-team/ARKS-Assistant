# Transport Unit分册编校记录

第5.0版，2026年10月20日。当前稿完成源码静态复核、编校、图文核对与全页校样，可供两类读者阅读及技术评审。

## 内容与设计说明

- 第1章补数据分离的设计关系与使用前提，第3章补配置读取和运行数据持有关系图。
- 第6章按S1与S2实际先后次序说明保留或新建TU的条件；不是仅依据“跨工位”推断重建。
- 第7章用同一输入4对比TU按Index查找与控制器按WorkIndex解析，避免把不同接口混用。
- 第8章画出目标接收源引用后Refresh抛异常的实际出口，保留两个区段暂指同一对象及部分几何更新的可能性。
- 贯穿算例统一数量、地址、工序名与坐标；交接保留工序进度与重建几何分别说明。

正文先介绍对象和问题，再解释数据、步骤与约束；接口与源码定位用于深入核查。编写说明提供研发评审和设备调试两种阅读路径，末章用可回查的问题核对理解。没有把源码文件列表当成设计正文。

## 图文与版面

- 15幅图、13张表；图注说明读法、前提、参考系或分支范围。概念图使用内置生图工具，数值、时序、字段和异常图按实际逻辑精确绘制，保存可维护图源。
- 标题、章节编号、目录统一微软雅黑；正文宋体。移除会覆盖显式字体的主题属性，Word更新字段后再次统一目录字体；核查实际PDF字体资源。
- 正文连续排版，附录分组。图、图注和解释相随；关键小表避免单行拖到次页；长字段与接口名称明确换行；不靠缩小正文来凑页数。
- Word保留原生目录、书签、公式和引用；图表页码使用可更新字段。PDF内所有字体已嵌入，所有插图保持不低于300dpi。
