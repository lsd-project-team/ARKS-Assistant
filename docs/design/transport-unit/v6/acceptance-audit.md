第6.0版，2026年10月20日。

| 要求 | 本轮依据 |
|---|---|
| 独立设计文档 | 保留职责、数据、坐标、主要流程、接口、约束及异常说明；两册分别组织 |
| 源码深入且可追溯 | 主要入口、计算、写回和返回边界可从引用追到source-guide及claim-map；当前源码哈希与锚点核对通过 |

| 计算明确 | 变量、单位、参考系、说明输入及独立复算保留；详见arithmetic-verification.json |
| 可继续维护 | PDF、Word、Markdown、所用SVG/PNG、来源和校样记录齐备 |
