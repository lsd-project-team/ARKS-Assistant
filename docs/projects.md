# 项目功能

项目将对话、源码目录、资料和回答指令放在一起。源码目录只是项目的一个关联项；空项目也可以正常对话。

普通用户只访问自己的项目和对话，项目内资料、结论、指令、记忆及浏览器草稿也按账号隔离。管理员保留全量管理。公司交接资料和调试问题继续共享。参见[项目与对话隔离](account-workspace-isolation.md)。

每个普通用户首次登录自动得到独立的“ZX2200 软件分析”项目，默认关联公司同一份源码和对应仓库。已有本人项目会复用，不复制别人的问答、资料或指令。普通用户新建项目也自动关联公司源码；独立对话同样可读取公司源码，无需管理员逐人手动绑定。只有公司已批准的源码目录可自动使用，任意服务器目录仍须管理员配置。

- 在侧栏“项目”旁新建项目，设置名称、说明和可选的源码目录。
- 选择或填写源码目录后，默认自动识别该目录自身的 GitHub Git 远端；没有远端时，复用同一目录已保存的项目仓库关联。创建时重新核对并保存，源码立即可读。无法确定或存在多个仓库时会提示手动填写，可关闭“自动关联 DeepWiki 仓库”后输入 `owner/repository` 或 GitHub 地址。
- 单击项目名称展开或收起下方对话列表，保持右侧当前页面；双击也不会打开项目首页。项目菜单的“查看项目与资料”打开首页。项目右侧的加号及项目首页的“新对话”在该项目中新建对话。顶部“新对话”、“最近对话”旁的加号和功能资料页的“开始新对话”都使用当前有效项目；未选项目、正在查看旧独立对话或项目已失效时，优先使用默认项目。
- 项目菜单提供重命名、置顶、上下移动、归档和恢复。项目首页可移除项目，并选择把对话保留为独立对话或移入回收站。
- 对话菜单可移动单个对话，项目首页可勾选并批量移动。移动保留消息和引用，后续回复使用目标项目的指令和资料。
- 搜索对话可以选择当前项目或全部项目。

左侧“最近、已归档、回收站”位于“项目”标题上方，标题右侧依次为新建项目和搜索。项目列表直接跟在标题下方。最近页先列项目及其缩进的对话，再列跨项目的最近对话；项目内默认显示三条，点击“展开显示”查看其余对话。项目可折叠，展开状态在切换项目和刷新后保留，当前选中的较早对话仍显示在预览中。归档页集中显示已归档项目和对话，回收站提供对话恢复入口。项目的新建对话、更多操作以及对话菜单在悬停或键盘聚焦时显示。

“最近对话”标题旁的加号悬停或键盘聚焦时显示。所有新建入口都沿用目标项目的源码、DeepWiki 仓库和知识来源设置，不需要重新配置。默认项目不可用时选择本人其他有效项目；没有有效项目时创建本人的独立对话。已有独立对话仍按原归属阅读，旧消息、草稿和引用保留。

已归档页顶部为“已归档项目”，直接列出项目，下方以“已归档对话”列出单独归档的会话。回收站顶部为“已删除对话”，直接列出删除条目。两页标题右侧仅保留搜索。搜索跟随当前标签：归档范围包含已归档会话及已归档项目下的正常会话，回收站只包含已删除会话；默认搜索该范围内的全部项目，也可以缩小到当前项目。选择回收站搜索结果会定位到条目，保留右侧当前对话，恢复后再打开。

“资料与指令”中可添加文档、导入文本文件、维护共享结论和编辑项目指令。文档导入目前支持 Markdown、TXT、CSV、JSON、YAML，单文件不超过 1.5 MB、50 万字符，每项目最多 200 份有效资料。可以将已完成回复保存为共享结论，保存前请整理并确认正文。助手不会自动将每条回复存入共享结论。

文档与共享结论采用带版本的只读检索；“本地知识资料”开启时，助手按问题检索并附资料引用。编辑或移入资料回收站后，旧回答中的引用仍显示原版本。共享结论表示用户确认的资料，涉及源码的判断仍需核对当前文件。资料内的文字不会作为项目指令。

主源码目录保留原有相对路径，最多再关联 8 个并列源码目录。附加目录在文件树分别显示，全文搜索和快速打开覆盖所有目录。同名文件用稳定的目录身份区分，解除关联不会删除实际文件。C# 语义分析以文件所在目录为边界，目录外的依赖会明确标记为缺失或未知。

项目指令保存后从下一次回复生效。运行时固定项目、模型配置和指令；切换页面或修改指令不会把正在运行的回复改到另一项目。各项目分别恢复上次的对话、源码阅读状态与新对话草稿。更换目录、移动对话后会重建后续上下文；旧源码引用仍按原目录打开。

归档项目可阅读已有对话和资料，但必须恢复后才能发起回复或改动资料。导出项目得到 ZIP，包含项目信息、原始对话、选区来源、资料历史版本和项目记忆。导出不复制真实源码，也不包含全局设置和 API 密钥。

原有对话自动归入“ZX2200 软件分析”，继续关联原 trunk 目录。已有流程图谱和功能说明只在关联原源码的项目中提供。独立对话不使用其他项目的文档、指令或项目记忆。

源码、DeepWiki 仓库和可用的流程与功能说明随项目切换；设置页“知识来源”显示当前关联。新项目不会复制其他项目的对话、资料或记忆。已有项目的手工仓库配置保留，可在项目设置中主动重新识别。自动关联只识别仓库身份，远端文档是否已建立仍取决于 DeepWiki；未配置仓库的项目不连接 DeepWiki，工具调用也不能改用其他项目的仓库。
