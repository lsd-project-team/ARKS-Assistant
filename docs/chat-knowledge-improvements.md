# 对话知识优化

用户约束（2026-10-15）：流程图谱和功能说明暂时不调整，包括内容、检索覆盖和源码复核规则。聊天中的文件上传入口继续预留，不开发上传。

本次实施及验收范围：

1. 个人偏好记忆按登录账号隔离，包含写入、读取、冲突检查、历史和恢复；项目记忆仍在项目内共享。旧公共用户记忆保留原件，不自动分配给任何账号。
2. 交接工作台资料（含原访谈正文）接入问答，固定版本和正文位置可追溯；归档、替代版本、待 OCR/部分解析内容有明确边界。
3. 调试记录和项目/交接资料支持关键词、同义词和本机语义检索；语义模型不可用时明确降级，不下载模型或上传资料。
4. 相似故障按明确的设备、版本、模块和工况筛选；未知条件提示补充，未解决记录不能成为已验证方案。
5. 显示本轮实际参考资料、检索状态以及记忆保存成功、待复核、失败的反馈；允许检索和实际返回的内容分别记录。
6. 使用可重建索引、版本缓存和批量读取，避免每轮重新读取全部正文；保持同轮引用版本固定。
7. 验证账号隔离、真实问题改写、条件冲突、空库、归档、更新、资料引用、来源开关和缓存；进行运行及页面验收。

所有测试资料只写入独立临时数据目录，不向正式工作区加入模拟资料。

## 已实施的行为

- `memory_identity.py`、`memory_visibility.py` 和运行的账号快照固定实际提问人。排队出队不继承上一位提问人的身份；个人记忆的正文、版本恢复、冲突缓存和运行详情均受账号范围约束。后续按用户要求增加[项目与对话隔离](account-workspace-isolation.md)，项目记忆只在本人项目内共享。
- 新个人记忆位于 `data/memories/users/<账号ID>/`，记录键带账号 ID。旧 `data/memories/user/` 原件及修订均保留，未自动认定归属；需明确归属后在对应账号保存。
- `handover/material_corpus.py` 接入资料正文与原访谈文本。`handover-source:ID/版本#L起行-L止行` 可打开固定版本并高亮正文；已替代、归档和不可读扫描件不作为新回答的正文依据。部分解析和摘录截断有明确标记。
- `knowledge_search.py` 为项目资料、交接资料和调试记录提供同义词、关键词与本机语义检索。按版本批量加载变化正文，复用倒排索引和向量矩阵；同一轮保留固定快照。派生缓存可重建，不改变业务原件或修订。
- 调试检索保留原问题里明确的设备、版本、S1/S2 模块、报警码和加热工况。AI 改写检索词不能取消这些条件；条件未知时标记待核对。条件不符的历史记录返回摘要和排除原因，可读取对照，但不能当成适用方案。
- “本轮参考”显示自动带入或工具实际返回的资料，不把仅允许使用的来源当成已检索结果。记忆保存成功、保存后待复核、冲突未保存和失败均来自实际工具结果。关闭自动保存时，来源文件名不能触发记忆保存。
- 引用以真实返回的标题和版本展示。未返回的资料版本或超出读取范围的链接标记为未核对，代码示例内的链接不改写。
