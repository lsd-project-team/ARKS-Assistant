## 1. 模块定位

### 1.1 职责边界

本范围内的 30 个文件做三件事：

1. **描述一层实体树**：`TransportUnit`（载具）→ `Substrate`（基板）→ `Module`（基岛）→ `BondPosition`（焊点），四层都继承 `BaseMatter`（`Module/Matter/BaseMatter.cs:22`），每层挂一个 `BaseInformation` 派生对象存运行时结果。
2. **保存产品配方配置**：`ProductConfiguration`（`ProductConfiguration.cs:22`，`Singleton<ProductConfiguration>`）是全局单例，聚合 `TransportUnitConfig` / `SubstrateConfig` / `ModuleConfig` / `BondPositionConfig` / `OtherConfig` / `OppositeSexConfiguration` 六份配置，序列化为单个 JSON。
3. **提供一组静态换算/读写工具**：`TuService`（`Service/TuService.cs:39`，`public static class`）里 30 个静态方法，负责行列索引换算、坐标系更新、视觉定位点解算、Mapping 文本文件读写、PR（视觉模板）复制。

### 1.2 在整机流程中的位置

上游：`TransportSystem/Controllers/TransportController.cs` 等控制器在皮带把载具送到位后 `new TransportUnit(...)` 建立数据对象（全仓 20+ 处构造点，例如 `TransportSystem/Tasks/TransportTask.cs:787`、`TransportSystem/Controllers/BondSubSectionController.cs:462`）。

下游：`BondSystem/Models/System2Domain.cs`（13 处调用 `TuService.`）和 `DispenseSystem/Models/System1Domain.cs`（11 处）拿着这个对象树去做固晶/点胶动作节点。

**关键结论：本层没有任何 IO、气缸、真空、轴运动代码。** 全范围内 grep `Thread|Task|Timer|event|lock|Invoke|async` 只命中 `using System.Threading.Tasks;` 这类无用 using，无一处真实并发原语（见 5.4 与第 8 节）。

### 5.3 状态机

本层有**两台互不相关的状态机**，都不是 IO 状态机。

#### (a) 制程状态机（`MatterProductState` 四级）

```
Disable（不启用，不参与任何工艺）
EnableInSystem1（只点胶）
EnableInSystem2（只贴片）
Enable（正常，两边都做）
```
- 定义：`Model/TuEnum.cs:278-302`。
- **叶子存储**：只有 `BondPosition` 真正存这个值（`BondPosition.cs:53` 继承基类 auto 属性，可写）。
- **向上聚合（只读重写）**：`Module.MatterProductState`（`Module.cs:46-47`）与 `Substrate.MatterProductState`（`Substrate.cs:38-39`）都是 `=>` 表达式体，由 `GetModuleMatterProductState()`（`Module.cs:278`）/`GetSubstrateProductState()`（`Substrate.cs:286`）实时计算：只要有子项 `Enable` → `Enable`；只有 `EnableInSystem1` → `EnableInSystem1`；否则 `Disable`。
- **迁移入口**：`SetMatterEnable()`/`SetMatterDisable()`/`SetMatterOnlyDispense()`/`SetMatterOnlyBond()` 在四个层级都实现，父层递归调子层（`TransportUnit.cs:556-595`、`Substrate.cs:323-362`、`Module.cs:329-368`、`BondPosition.cs:205-233`）。
- 复位为"全部不启用"的入口：`OtherConfig.ClearInformation()`（`OtherConfig.cs:38`）与 `Module.ChangeBondPositionProductInformation(MatterProductState)`（`Module.cs:180`，**无调用者**）。

#### (b) 示教（Assistant）状态机（三态顺序门禁）

```
ForBidden（本配方不需要）   UnAble（需要但未做）   Able（已完成）
```
- 定义在平台层 `AssistantState` / `AssistantStateEnum`（`AKRS.Galaxy2.MachineSupport`，**黑盒**），本层只使用。
- 载具级 16 个状态字段集中在 `TransportUnitConfig`（`TransportUnitConfig.cs:166-243`）：`TUPosition`、`TUAdjust`、`TUIdentification`、`TUHeightMeasurement`、`SubstratePosition`、`SubstrateAdjust`、`SubstrateInkDot`、`SubstrateIdentification`、`SubstrateHeightMeasurement`、`ModulePosition`、`ModuleAdjust`、`ModuleInkDot`、`ModuleHeightMeasurement`、`BadModuleTable`、`ModuleIdentification`、`Mapping`。
- **默认值**：`TUPosition = UnAble`（唯一非 `ForBidden` 的初值），其余全 `ForBidden`（`TransportUnitConfig.cs:166-243`）。
- **整机门禁**：`IsAssistantSucceed`（`TransportUnitConfig.cs:249`）→ `GetAssistantResult()`（`:255`）：异性基板走 `OppositeSexConfigs.AssistantSuccess()` 递归（`OppositeSex.cs:180-198`）；否则遍历上述列表，**只要有一个 `UnAble` 就返回 false**。开机时 `Main/Machine/MachineSupport/Machine.Operate.cs:110` 通过 `ProductConfiguration.IsTransportUnitReady()`（`ProductConfiguration.cs:89`）拦截，提示"框架未示教完成，请示教完成后启动"（`ProductConfiguration.cs:94`）。
- **顺序门禁**：`IsNormalOrderAssistant(name)`（`TransportUnitConfig.cs:308`）——在列表中定位当前步骤，**要求它之前的每一步都不能是 `UnAble`**，否则弹框 `请先完成步骤：{ChName}`。
- **重置**：`ResetAssistantStates()`（`TransportUnitConfig.cs:336`）全部 `Able→UnAble`，再按开关把 `TUAdjust`/`TUHeightMeasurement`/`SubstratePosition` 等重设为 `UnAble` 或 `ForBidden`。**注意该方法的唯一调用点被注释掉了**（`TransportUnitConfig.cs:160`），即目前只在手工显式调用时生效。
- 焊点级另有 5 个状态：`TeachBondingPosition`/`MoveToBondingPosition`/`BondPositionAdjust`/`BondPositionMeasureHeight`/`BondPositionIdentity`（`SingleBondPositionConfig.cs:152-172`），聚合入口 `IsAssistantSucceed`（`:178`）。

#### (c) 制程步骤状态机（`Dictionary<string,bool>`）

- `BondPositionInfo.S1RemainingSteps` / `S2RemainingSteps`（`BondPositionInfo.cs:107/112`）——key 是步骤名，value 是"已完成"。
- 查询：`IsFinishedInSystem1()`（`:118`）——`S1RemainingSteps` 为空直接 true；再若 `S2RemainingSteps` 为空则 false（**空 S2 字典视为"还没开始"**）；否则要求所有 value 为 true。`IsFinishedInSystem2()`（`:145`）只检查 `S2RemainingSteps` 自己的空/全真。
