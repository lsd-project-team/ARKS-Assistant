# Linux临时运行验收

本脚本启动真实uvicorn、执行本机HTTP请求及自带Roslyn helper，只使用自建微型C#项目。不会启动Agent、请求模型供应商、执行验证命令或业务程序。

由操作者提供仓库外的绝对空目录：

```sh
ARKS_LINUX_SMOKE_ROOT=/tmp/arks-linux-smoke python -m scripts.verification.linux_runtime
```

跨挂载恢复验收可另设`ARKS_LINUX_SMOKE_RESTORE_ROOT=/restore-volume`，提供独立空挂载根。脚本核对其设备号与主临时根不同，把该目录本身作为恢复目标；不会改成其子目录或删除挂载根。此目录也生成本轮归属标记，标记不属于备份清单。

必须事先安装助手依赖、编译自带Roslyn helper并准备`frontend/dist`。运行时不安装依赖、不构建业务工程；缺少前置条件会失败。建议在无外网、没有正式`data/`与`trunk/`的临时Linux应用容器中运行。脚本不会创建Docker容器，容器准备与删除由调用者负责。

临时根所在文件系统必须满足现有项目空间策略：默认至少保留1 GiB空闲空间，再加夹具和暂存所需空间。使用tmpfs时建议提供2 GiB容量；恰好1 GiB的tmpfs写入数据库后会触发空间保护，不能通过降低产品的空间门槛让验收通过。

检查健康接口、静态JS/CSS、公司域名Origin登录及CSRF/Host拒绝、重复数据目录进程锁、真实Roslyn符号/重载/接口候选与调用方、隔离副本编辑和原件哈希、SQLite WAL一致性、资料/附件重启持久化、在线备份及异地恢复后的HTTP读取。

还会读取当前构建的Vite清单，验证非公开JS分包和知识直链在未登录时均拒绝，登录后返回与构建文件完全相同的字节。需携带标准构建生成的 `.vite/manifest.json` 与 `public-assets.json`，不能用旧页面或只替换首页代替完整发布。

输出仅有临时根中的`report.json`，包含检查名称、布尔值、fixture原件哈希及通用错误类别。初始化账号仅来自本轮临时data，引导文件读取后删除，密码只在内存保留；输出不含密码、Cookie、CSRF、数据库或资料正文。失败时日志也只保留在本轮临时根，不能作为公开报告导出。

脚本拒绝现有非空目录、应用目录及其父目录、链接路径；不清理或接管其他目录，不自动重试复用已有数据。运行数据由操作者删除本次精确临时容器或目录时清理。
