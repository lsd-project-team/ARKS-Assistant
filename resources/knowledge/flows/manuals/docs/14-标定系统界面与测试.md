# 标定系统界面与测试（AKRS.ZX2200/CalibSystem 的界面层与实验窗体）

> 标定系统的「壳」：示教向导窗体、标定结果确认窗体、以及一大堆实验/调试窗体。
> 代码规模：21 个文件 / 9,130 行（不含 `*.Designer.cs`）；另有 16 个 `*.Designer.cs` / 5,024 行、16 个 `*.resx`。

本文件只覆盖 `CalibSystem/Controls/`、`CalibSystem/Test/`、`CalibSystem/TestControls/` 和 `CalibSystem/` 根目录散文件。
`GlobalCalibration/`、`GlobalCalibrationEnd/`、`Models/`、`Services/` 见 `13-整机标定.md`；`Experiment/` 见 `16`/`17`。

## 1. 模块定位

标定系统的算法与流程在 `Models/CalibrateTask.cs`（2405 行，见 `13-整机标定.md`）里，本范围内**几乎没有标定算法**，只有三类东西：

1. **示教向导窗体**（`Controls/Assistant/`，9 个文件）——产线工程师真正会用的界面。用 `AssistantConfig` 列表驱动「上一步 / 下一步 / 完成」，每步要求操作员用方向盘把某个模组移到某个位置，点「下一步」时把当前机械坐标写进 `CalibrateRunPara`（JSON 持久化）。
2. **标定结果确认窗体**（`Controls/FrmCalibResult.cs`，67 行）——只读表格，按下「确定」和「取消」效果完全一样（见第 4、8 节）。
3. **实验/调试窗体与算法**（根目录 `FrmTestAccuary.cs`、`Test/TestAlg.cs`、`TestControls/` 5 个窗体）——产线不该出现的东西，但**部分确实挂在主菜单上**（见第 4.4 节）。

**上游**：主界面 ribbon（`Main/Controls/Ucmain/MainControls/UcMainSystem.cs`）是唯一的正常入口。
**下游**：全部落到 `CalibrateRunPara`（`CalibSystem/Models/CalibrateRunPara.cs`）、`MachineCoordinateSystem`、`BondDevicePara`、`LightCalibrationPara`，以及 5 家坐标系对象。
