## 1. 模块定位

本模块是**固晶子系统的"表层"**：一边是操作员能点到的窗体和控件，另一边是这些界面存读的参数对象。

- **上游**：`Main/Controls/Ucmain/`（主界面菜单、快捷键、诊断/手动/数据管理面板）以及 `Infrastructure/Controls/Feature/EditProgram/UcEditProductProgram/`（产品编程向导）负责**弹出**本模块的窗体；`BondSystem/Controllers/` 提供运动/视觉能力。
- **下游**：`Models/` 下的模型被 3 条链路消费：
  1. **持久化**：`Infrastructure/Models/BaseModels/BaseSettingRepository.cs:34` 的 `BaseSettingRepository<T>` / `Infrastructure/Models/BaseModels/BaseDsSetting.cs:35` 的 `BaseDsSetting` / `AKRS.Galaxy2.Infrastructure.CommonModel.Singleton<T>` 按 `ZX2200PathConfig` 给出的 JSON 路径读写；
  2. **运行期**：`BondSystem/Tasks/BondTask`、`Models/ActionNodes/*` 在固晶节拍里读 `System2Domain` / `System2RunTimeProvider` / `BondDevicePara`；
  3. **自检**：`System2Domain.CheckIsReady()`（`Models/System2Domain.cs:594`）在启动线程前逐个校验这些参数是否已示教。
